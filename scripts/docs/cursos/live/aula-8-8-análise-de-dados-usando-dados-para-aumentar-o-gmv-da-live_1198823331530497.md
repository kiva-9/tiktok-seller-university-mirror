Este curso tem como objetivo capacitar vendedores a realizar o diagnóstico pós-live com base nos principais indicadores de desempenho do TikTok Shop.Durante a formação, os participantes aprenderão a analisar métricas essenciais — como GPM, ticket médio, taxa de conversão e as etapas do funil da live — identificando gargalos que vão desde a exposição inicial até o fechamento da compra.A metodologia aplicada contempla o modelo das **cinco dimensões** e **quatro taxas**, permitindo uma avaliação aprofundada de problemas relacionados à entrada na live, exposição de produtos, cliques e conversão.
