Aqui está um guia rápido e fácil sobre como processar pedidos "Enviados pela plataforma".  

# **Visão geral do processamento de pedidos**

Os vendedores empresariais devem fornecer uma nota fiscal para todos os pedidos. Para isso, eles precisam **carregar** a nota durante o processamento do pedido, depois **imprimi-la** e **anexá-la** ao pacote. Siga estas etapas para processar os pedidos e garantir a conformidade com as normas tributárias do Brasil.

This content is only supported in a Feishu Docs  

## **Como carregar sua nota fiscal**

1. Seleção dos pedidos "Para enviar" com status de nota fiscal "Upload pendente"
   * Etapa 1: Verifique seus pedidos recebidos em "Gerenciar pedidos > Para enviar".
   * Etapa 2: Selecione o status de nota fiscal "Upload pendente".

     ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/64df88c95b134ac9be92af6754263fa1~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2058936944&x-signature=fFVFQ2eJWnkiGgFPNVVK1YW%2BP4I%3D)
2. Upload de notas fiscais para seus pedidos

Você pode optar por carregar a nota fiscal para um **único pedido** ou **vários em lote**.

## **Motivos Comuns de Falha no Envio da Fatura**

Após o envio da sua fatura, aparecerá uma janela pop-up mostrando o resultado do envio. Se o resultado indicar "Falha", verifique o **Motivo da Falha** exibido na janela pop-up e siga as ações recomendadas abaixo para corrigir o problema e reenviar sua fatura.  

|  |
| --- |
| image |

|  |  |  |
| --- | --- | --- |
| **Mensagem de Erro** | **Explicação** | **Ações Recomendadas** |
| ID do pacote ausente ou inválido | Nenhum ID de pacote fornecido ou o ID está incorreto. | Verifique se o ID do pacote foi inserido corretamente e não está ausente. |
| ID do pedido ausente ou inválido | Nenhum ID de pedido fornecido ou o ID está incorreto. | Confirme se o ID do pedido está correto e corresponde ao do seu sistema. |
| Código da fatura ausente ou inválido | O código da fatura está ausente ou incorreto. | Verifique e insira o código da fatura no formato correto. |
| Você selecionou manter a fatura antiga. | Você escolheu usar uma fatura anterior inválida. | Envie uma nova fatura em vez de selecionar a anterior. |
| ID do pedido ou ID do pacote duplicado | O mesmo ID de pedido ou de pacote aparece mais de uma vez no documento. | Garanta que cada ID de pedido e pacote seja único no arquivo de envio. |
| Uma fatura está sendo processada. Tente novamente mais tarde. | Outra fatura para o mesmo pedido ainda está sendo processada. | Aguarde o envio anterior ser concluído antes de tentar novamente. |
| Envio de fatura não é necessário para pedidos enviados pelo vendedor | Pedidos enviados diretamente pelos vendedores não exigem envio de fatura. | Nenhuma ação necessária – pule o envio da fatura para esse tipo de pedido. |
| Fatura já enviada. | A mesma chave de fatura já existe no sistema. | Verifique se o envio anterior foi bem-sucedido. Evite reenviar a mesma fatura. |
| Tente novamente mais tarde. | Problema temporário no sistema. | Aguarde alguns instantes e tente reenviar novamente. |
| Algo deu errado. | Ocorreu um erro no sistema. | Tente novamente mais tarde ou entre em contato com o suporte se o problema persistir. |

## **Como processar seus pedidos depois de carregar a nota fiscal**

**Importante:** verifique sua nota fiscal antes de processar seus pedidos.

Lembramos que, no momento, não é permitido modificar a nota fiscal após a conclusão da etapa de envio do pedido. Para evitar qualquer problema, revise com atenção a nota fiscal enviada antes de continuar o processamento dos pedidos.

1. Selecione os pedidos "Para enviar" com status de nota fiscal "Carregada".

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/7d6063e569e942fcb82230c4b15f5d74~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2058936948&x-signature=luq4qJCzwqGv7zHxH3L19XI0n7k%3D)
2. Você pode optar por "Providenciar envio" para um **único pedido** ou **vários em lote.** Quando você terminar de providenciar o envio, os pedidos serão enviados automaticamente ao responsável pela entrega.

|  |  |
| --- | --- |
| Upload para pedido único | Upload em lote |
| image | image |

No **primeiro processamento de pedidos**, você deverá definir "Providenciar envio" ou "Providenciar envio e imprimir" como a ação padrão. Selecione o que preferir.

* **Providenciar envio e imprimir:** imprime instantaneamente os documentos ao providenciar o envio.
* **Providenciar envio:** permite a seleção manual dos documentos para impressão depois de providenciar o envio.

Se quiser alterar sua configuração padrão, consulte mais informações no [Guia de configuração de pré-envio para novos vendedores](https://seller-br.tiktok.com/university/essay?knowledge_id=5235393046546177 "https://seller-br.tiktok.com/university/essay?knowledge_id=5235393046546177").

3. Os documentos de envio serão impressos de acordo com os documentos selecionados para impressão.

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/538d781bd7f04c24b2eeff82db766510~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2058936946&x-signature=6q8pzU821xlKn6gCX2ovWkuTFpY%3D)

## **Como corrigir problemas se a impressão da minha etiqueta de envio falhar**

Em caso de problema ao tentar imprimir uma etiqueta de envio e o conteúdo da embalagem, todas as falhas serão exibidas no **resultado de impressão.** A exibição incluirá as IDs dos pedidos e os motivos da falha de impressão.

Você pode tentar imprimir novamente clicando em **"Reimprimir pacotes com falha"** ou pode optar por **"Exibir etiquetas de envio"** para obter informações mais detalhadas.

## **Como reimprimir etiquetas de envio**

Depois de resolver os problemas com as etiquetas que falharam e estiver com tudo pronto para recriá-las ou reimprimi-las, siga estas etapas na nova página **Etiquetas de envio**.

1. Para acessar a página "Etiquetas de envio", navegue até [Gerenciar pedidos > Etiquetas de envio](https://seller-br.tiktok.com/shipment/labels "https://seller-br.tiktok.com/shipment/labels"). Aqui, você encontrará uma lista abrangente de todas as etiquetas de envio que já gerou.

|  |  |
| --- | --- |
| image | image |

2. Localize os pedidos específicos para os quais você deseja recriar ou reimprimir etiquetas de envio filtrando os pedidos com base no status da etiqueta.
3. Depois de filtrar os seus pedidos, selecione os pedidos individuais ou use a seleção múltipla. Em seguida, clique em **"Criar etiquetas"** ou **"Imprimir documentos"**, dependendo da ação que deseja realizar.
