Você pode modificar a divisão dos pedidos desde que estejam no processo **"Aguardando Envio"** antes do status "Aguardando Coleta". Você não pode editar a configuração de divisão depois de ter organizado um dos pacotes para envio.

Depois de confirmar a divisão do pedido e organizar a entrega, os clientes podem revisar seus pedidos no TikTok Shop.

## **Guia de divisão de pedidos**

Siga os passos abaixo para dividir um pedido.

### **Como encontrar pedidos divisíveis**

Vá para **Gerenciar Pedido**

1. No menu **Pedidos** > **Gerenciar Pedidos**, considere um pedido que tenha mais um ou mais tipos de SKU.

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/4ee73aa5f62b4f8488f5e4e8007dcd51~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059593775&x-signature=ca8HbFnbuBOfDwIyQbLHsY3yoIY%3D)
2. Clique em **Dividir pedido.** O botão estará disponível apenas em pedidos que podem ser divididos.

### **Divisão de pedido**

1. Divida-os em pacotes diferentes clicando em **"Mover para Novo Pacote".**

Uma vez clicado, o custo estimado de envio do pacote será mostrado. Observe que o custo de envio é apenas para referência quando os vendedores dividem o pedido. A taxa de envio real é sempre mostrada no Faturamento do Vendedor (menu Finanças).

2. Depois de clicar no botão **Dividir pedido** no menu Pedidos ou no menu Envio, você verá vários SKUs contidos no pedido e um botão para dividi-los em diferentes pedidos ou **redefiní-los para um pacote novamente**.

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/60eb8acac5f54b8fbef915b9ddc1957b~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059593770&x-signature=KKlNEhP6i9a%2B%2FUPYdIS%2BLvSb%2B6w%3D)

### **Revisão de divisão de pedido**

Depois de dividir um pedido, você pode encontrá-lo na página Gerenciar Pedidos e nos resultados de pedidos baixados.

|  |  |
| --- | --- |
| 1. Pedidos que foram divididos terão a tag **Dividido**. | image |
| 2. Você pode filtrar pedidos que foram divididos no **botão Filtro > Pedido Combinado/Dividido > Já** **Dividido**. Em seguida, clique em **Aplicar**. | image |
| 3. Após a filtragem, você pode ver uma lista de pedidos que foram divididos. Você também pode baixar um pedido clicando no botão **Exportar Pedidos**. No arquivo de resultados de exportação, haverá diferentes IDs de pacote sob o mesmo ID de pedido para pedidos que foram divididos. | image |

### **Editar pedido dividido**

Você ainda pode editar um pedido que foi dividido antes de organizar o envio (antes que o status mude para **Aguardando Coleta**). Altere-o no menu Gerenciar Pedidos:

|  |  |
| --- | --- |
| 1. Filtre um pedido **Já Dividido** | image |
| 2. Clique em **Editar Divisão**. |

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/0fc92b7826f34539887b47c5c2492cd5~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059593777&x-signature=3ot3Jh27HLvnoKxYl6vgt%2B7oOiI%3D)
