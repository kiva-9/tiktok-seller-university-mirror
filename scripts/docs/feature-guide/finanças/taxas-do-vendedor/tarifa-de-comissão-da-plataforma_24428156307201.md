Cada pedido vendido no TikTok Shop está sujeito a uma tarifa de comissão e a uma tarifa por item vendido. Este artigo apresenta aos vendedores essas duas tarifas, como elas são calculadas e as isenções às quais os vendedores podem ter direito.

A partir de **15 de julho de 2026, às 00:00:00 (horário do Brasil)**, **o TikTok Shop ajustará a tarifa de comissão e a taxa por item vendido** da seguinte forma:

|  |  |  |  |
| --- | --- | --- | --- |
| Preço do item após os descontos do vendedor | Tipo de taxa | Antes | Depois (Vigente a partir de 15 de julho de 2026) |
| < R$ 50,00 | Tarifa de comissão | 6% | **10%** |

| ≥ R$ 50,00 | Tarifa de comissão | 6% | 6% |
| taxa por item vendido | R$ 4,00 | **R$ 6,00** |

## **Definições de Taxas e Regras de Cálculo**

1. ### **O que é uma tarifa de comissão?**

A tarifa de comissão é uma porcentagem específica do valor total de um pedido, cobrada aos vendedores pelo TikTok Shop referente ao uso da plataforma.  

2. ### **O que é a Tarifa por Item Vendido?**

O TikTok Shop cobra uma taxa por item vendido para itens cujo subtotal já inclui o desconto do vendedor.  

3. ### **Nota Importante sobre a Base de Cálculo**

Observe que essas taxas são calculadas com base no preço do item após os descontos do vendedor, sem incluir o desconto da plataforma.  

### **Exemplo**

1. Item 1: uma camisa

* Preço original: R$ 45,00
* Desconto do vendedor: R$ 0,00

2. Item 2: uma calça

* Preço original: R$ 85,00
* Desconto do vendedor: R$ 10,00

|  |  |  |
| --- | --- | --- |
|  | **Camisa** | **Calça** |
| Preço original | R$ 45,00 | R$ 85,00 |
| (-) Desconto do vendedor | R$ 0,00 | R$ 10,00 |
| **(Preço original - Desconto do vendedor)** | R$ 45,00 | R$ 75,00 |
| **(\*) Taxa da tarifa de comissão** | 10,00% | 6,00% |
|  |  |  |
| **Tarifa de comissão** | R$ 4,50 | R$ 4,50 |
|  |  |  |
| **Taxa por item vendido** | **R$ 4,00** | **R$ 6,00** |
|  |  |  |
| **Taxa total do pedido** | **R$ 8,50** | **R$ 10,50** |

## Incentivo à redução da taxa

Para otimizar o mecanismo de incentivos aos comerciantes, a partir de 1 de março de 2026, ajustaremos o incentivo de redução de comissões para os novos comerciantes — incluindo aqueles que apresentaram a solicitação de cadastro na plataforma e ainda se encontram em análise. Os vendedores que concluem a nova missão do vendedor e resgatam a recompensa de missão podem aproveitar uma taxa de comissão de 0%. Essa redução de comissões dura 60 dias e tem um limite de R$ 17.000.  
Os vendedores podem verificar as missões e resgatar recompensas de conclusão em [Central do vendedor > Crescimento > Oportunidades de crescimento.](https://seller-br.tiktok.com/challenges/growth "https://seller-br.tiktok.com/challenges/growth") Saiba mais sobre o crescimento de vendedores [aqui](https://seller-br.tiktok.com/university/essay?knowledge_id=6859244688148240 "https://seller-br.tiktok.com/university/essay?knowledge_id=6859244688148240"). Observação: a missão deve ser concluída antes de expirar. Não a concluir resultará na perda automática da recompensa.

## **Notas**

* A TikTok Shop pode oferecer reduções de comissões por um tempo limitado como parte dos incentivos ao vendedor. Consulte as atualizações de incentivo mais recentes na Central do vendedor ou verifique a tarifa de comissão mais recente em [Central do vendedor > Finanças > Demonstrações](https://seller-br.tiktok.com/finance/bills?subTab=bills&tab=statements "https://seller-br.tiktok.com/finance/bills?subTab=bills&tab=statements").
* O TikTok pode, a seu exclusivo e absoluto critério, alterar a taxa da tarifa de comissão de tempos em tempos e informará os vendedores sobre tal alteração por escrito ("Aviso") com bastante antecedência e de acordo com os termos de jurisdição adicionais aplicáveis.
