# Introdução: o que é Anunciar com URL?

Anunciar com URL é um novo recurso com o qual os vendedores, que têm anúncios em outros marketplaces, podem anunciar esses produtos com tranquilidade no TikTok Shop por meio de URL. Com esse recurso, os vendedores podem copiar e colar os URLs dos produtos (disponíveis em outros marketplaces) e, por meio dessas informações do produto, criar rapidamente um anúncio, que o vendedor pode editar antes de anunciar na própria loja do TikTok Shop.  

# Quais sãos os benefícios?

* **Redução do tempo necessário** para que os vendedores com anúncios em outros marketplaces anunciem esses produtos no TikTok Shop
* **Redução do esforço necessário** para preencher as informações do anúncio que já estão disponíveis em outros marketplaces
* **Aumento da facilidade** para vendedores novos e atuais

# Etapas

O recurso Anunciar com URL pode ser encontrado na Central do Vendedor, quando acesso do computador.  

## **Como criar um novo anúncio na Área de trabalho**

1. Entre na Central do vendedor. Acesse "Produtos" e, depois, "Gerenciar produtos" e

# Perguntas frequentes

1. **Posso copiar de qualquer marketplace?**

Atualmente, este recurso é compatível principalmente com links de URL do **Mercado Livre** e da **Amazon**.  

2. **Posso copiar o URL de toda a minha loja?**

Não. Somente produtos individuais podem ser copiados usando este recurso.  

3. **Posso copiar meu produto , mesmo que eu não tenha autorização da marca para este item?**

Se não tiver a autorização da marca para o produto desejado, você não poderá copiar as informações dele. Para continuar, peça autorização à marca. Consulte o guia: [Guia sobre Autorização da marca](https://seller-br.tiktok.com/university/essay?knowledge_id=5407942887311105&role=1&course_type=1&from=search%7BcontentIdParams%7D&identity=1 "https://seller-br.tiktok.com/university/essay?knowledge_id=5407942887311105&role=1&course_type=1&from=search%7BcontentIdParams%7D&identity=1").  

4. **Posso editar as informações do produto copiadas?**

Sim, você pode editar as informações copiadas para adequá-las às necessidades do anúncio.
