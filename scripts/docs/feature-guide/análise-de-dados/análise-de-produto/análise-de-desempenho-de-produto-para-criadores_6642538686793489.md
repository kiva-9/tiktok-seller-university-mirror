## **Como usar a Análise de produto**

1. **Veja as métricas de produto de alto nível:** localize os produtos que estão gerando mais receita, comissão e reembolsos, para que você possa otimizar sua estratégia de produto.
2. **Análise de produto aprofundada:** clique em qualquer produto para detalhar os principais indicadores de desempenho.
3. **Compreenda o desempenho de produto dos diferentes canais: verifique** quais canais estão gerando o maior número de conversões, transmissões ao vivo, vídeos ou vitrines.
4. **Analise o funil de conversão:** comparando as taxas de conversão dos diferentes produtos, obtenha mais insight sobre quais produtos estão sendo abandonados, para que você possa otimizar o desempenho.

## **Perguntas frequentes**

**Por que não há dados sobre os módulos de perfil de usuário e indicadores UV ao escolher um intervalo de tempo personalizado?**

Ao selecionar um intervalo de tempo personalizado, os indicadores UV (número de usuários) não são exibidos porque não podem ser desduplicados. É recomendável visualizar os indicadores UV usando o período de últimos 7 dias, últimos 28 dias, dia, semana e mês.

Ao selecionar um intervalo de tempo personalizado, o módulo de análise de usuário não será exibido. É recomendável visualizar a análise do usuário usando o período de últimos 7 dias, últimos 28 dias, dia, semana e mês.
