# Introdução ao Recurso

## Para quem é isto?

**Se você é:**

* Um comerciante com alta proporção de GMV gerado por LIVE na sua loja, **especialmente aqueles cujo negócio depende fortemente de LIVE de criadores**
* Um comerciante que acredita que a promoção de produtos por criadores é muito útil e **espera obter novo crescimento de negócios**, mas tem dificuldade em encontrar criadores adequados
* Um comerciante que **falta experiência em entrega de anúncios ou está muito ocupado com operações diárias** para otimizar a veiculação de anúncios

**LIVE de Loja Única para Anúncios (SSLA) é uma solução de produção em uma etapa feita sob medida para você!** 

**O SSLA pode:**

* Ajudar você a **expandir o GMV de LIVE de criadores**, entregar anúncios com precisão em salas de LIVE de loja única dedicadas e acelerar o crescimento do seu negócio na loja
* Integrar a capacidade de correspondência de criadores do LIVE de loja única, para que os criadores possam **visualizar os requisitos do LIVE de loja única com prioridade** após os comerciantes emitirem o pedido de LIVE de loja única
* **Simplificar o fluxo de criação de conteúdo****:** o sistema pode criar e gerenciar automaticamente anúncios para múltiplos criadores, eliminando a necessidade de operações manuais por criador e por transmissão ao vivo

## Como funciona o SSLA?

|  |  |  |
| --- | --- | --- |
| **Etapa** | **Quem faz** | **O que acontece** |
| **① O comerciante preenche o formulário LIVE de Loja Única para Anúncios (SSLA)** | Comerciante | Indica a intenção de veicular anúncios na sessão de LIVE de loja única e define o ROI alvo e o orçamento para a veiculação de anúncios dedicada com antecedência. |
| **② Criadores escolhem a sessão de LIVE de loja única** | Criador | Quando um criador está em preparação pré-live e identifica uma oportunidade de veiculação de anúncios de um comerciante, ele pode escolher este comerciante para hospedar sessões De loja única, onde uma sessão single-shop apresenta apenas produtos de uma loja correspondente.  *Se você preencher o formulário SSLA com antecedência, sua loja será priorizada para exibição aos criadores.* |
| **③ Veiculação automática de anúncios pelo sistema SSLA** | Plataforma | Depois que o criador seleciona uma sessão dedicada e entra em LIVE, o sistema criará automaticamente um anúncio LGM e iniciará a veiculação. |
| **④ Liquidação e Divulgação** | Plataforma | O GMV gerado pelo SSLA é liquidado com base na comissão de shop ads (*requer configuração separada*), enquanto o GMV de tráfego orgânico é liquidado com base na comissão padrão.  Os dados de veiculação de anúncios serão divulgados simultaneamente no módulo de publicidade e no Seller Center. |

## Principais Benefícios

|  |  |
| --- | --- |
| **Pontos de Dor Atuais ❌** | **Soluções SSLA ✅** |
| Os comerciantes **não fazem ideia de quais criadores farão sessões de LIVE de loja única** para eles, portanto não podem agir. | **Equipado com um sistema de correspondência integrado**, melhora a taxa de sucesso de correspondência entre comerciantes e criadores de sessões LIVE de loja única:  *Depois que um comerciante indica a intenção de publicar um pedido de LIVE de loja única, o backend do criador priorizará a recomendação de lojas de comerciantes que têm disposição de veicular anúncios de sessões dedicadas.* |
| Em transmissões ao vivo tradicionais, os comerciantes relutam em investir em anúncios, pois **se preocupam que o tráfego de anúncios possa ser atingido por produtos de outras lojas**. | **Alocar precisamente o orçamento em salas de LIVE exclusivas** para impulsionar o GMV da sala de LIVE:  *Uma sessão de LIVE exclusiva por um criador apresenta apenas produtos desta loja, então o orçamento de anúncios não será desviado para produtos de outras lojas, tornando o investimento em anúncios mais eficiente.* |
| Criar anúncios, monitorar desempenho e fazer otimizações para cada criador individualmente **leva a altos custos de mão de obra e operacionais**. | **O sistema identifica automaticamente todos os criadores** para sessões de LIVE de loja única e conduz a veiculação de anúncios, **com orçamento priorizado para salas de LIVE de alta qualidade**:  *O sistema pode criar e gerenciar automaticamente anúncios para múltiplos criadores que realizam sessões exclusivas para comerciantes, eliminando a necessidade de operações manuais por criador e por sessão de transmissão ao vivo, enquanto otimiza o desempenho das salas de LIVE de múltiplos criadores em tempo real.* |
| Preocupação que **a combinação de gastos com anúncios e comissões de criadores leve a altos custos**. | **Comissões** **diferenciadas para anúncios e conteúdo orgânico**:  Os comerciantes podem personalizar a taxa de comissão de shop ads para pedidos relacionados a anúncios para evitar gastos excessivos em comissões de criadores somados ao orçamento de veiculação de anúncios. |
| Preocupação com **nenhum retorno após a veiculação de anúncios e altos custos de tentativa e erro** | **Modelo de Vendas líquidas** **para garantir que cada centavo valha**:  *Na premissa de atender ao alvo de retorno sobre investimento do comerciante, as taxas são cobradas com base na Receita Bruta, e o valor gasto em pedidos cancelados será reembolsado automaticamente para garantir a eficácia da utilização do orçamento.* |
