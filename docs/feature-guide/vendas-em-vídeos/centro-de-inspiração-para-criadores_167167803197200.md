# **Centro de Inspiração para Criadores**

O Centro de Inspiração para Criadores do TikTok Shop é um recurso integrado à plataforma, desenvolvido para ajudar criadores a descobrir ideias de conteúdo, acompanhar as tendências e aumentar sua monetização por meio de insights e exemplos baseados em dados. Lembre-se: o material fornecido é apenas para inspiração. Certifique-se de criar conteúdos originais!  
**Principais funcionalidades:**

* **Explore conteúdos virais:** Acesse vídeos de alto desempenho relacionados ao TikTok Shop.
* **Descubra oportunidades de produtos:** Encontre produtos em alta ou mais vendidos para promover e obter mais conversões.
* **Aprenda com outros criadores:** Analise como os principais criadores apresentam e estruturam seus conteúdos.
* **Planeje conteúdo de forma mais inteligente:** Use o feed de inspiração para superar bloqueios criativos e acelerar o processo de planejamento de conteúdo.

## **Como usar o Centro de Inspiração?**

### **Melhor desempenho para se inspirar**

|  |  |
| --- | --- |
| **No Centro de Inspiração, há 4 filtros para te ajudar a encontrar os vídeos certos:**  * **Para Você:** recomenda vídeos relacionados aos produtos que o criador adicionou à sua vitrine/carrinho ou visualizou no marketplace. * **Amados pelos Seguidores:** recomenda vídeos com base nas categorias de produtos que os seguidores do criador visualizaram ou compraram. * **Em Alta:** recomenda vídeos de categorias que tiveram aumento no GMV ou no volume de pedidos. * **Favoritos:** permite que os criadores salvem os vídeos que gostaram para facilitar a comparação e referência. | image |

### **Pesquisa no Centro de Inspiração**

|  |  |
| --- | --- |
| Os criadores podem usar palavras-chave ou nomes de produtos para fazer buscas no Centro de Inspiração. Serão exibidos vídeos que promovem esses produtos, ajudando os criadores a aprender e se inspirar para criar seu próprio conteúdo. | imageimage |

### **Insights do Vídeo**

|  |  |
| --- | --- |
| No vídeo exibido no Centro de Inspiração, os criadores podem identificar o produto apresentado e adicioná-lo diretamente à sua vitrine ou acessar a Página de Detalhes do Produto (PDP) para explorar mais informações e ver outros vídeos relacionados.Também serão exibidas as métricas de visualizações, curtidas, comentários e compartilhamentos do vídeo. | imageimage |

### **Criação de Vídeo**

Por fim, , depois de ter acesso a diversas referências e dicas para ajudá-lo a criar o seu próprio conteúdo, é só clicar em “Criar” para começar a produzir seu vídeo, mostrar sua criatividade e começar a monetizar.
