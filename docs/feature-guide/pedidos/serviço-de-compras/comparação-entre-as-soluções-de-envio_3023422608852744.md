## Diferenças entre as opções "Enviado pela plataforma" e "Enviado pelo vendedor"

|  |  |  |
| --- | --- | --- |
| **Recurso** | **Enviado pela plataforma** | **Enviado pelo vendedor** **(apenas para vendedores selecionados)** |
| Inscrição | Por meio da Central do vendedor (configuração padrão para novos vendedores) | Por meio da Central do vendedor*Nota: a opção "Enviado pelo vendedor" está disponível apenas para vendedores selecionados até novo aviso.* |
| Armazenamento de estoque antes do envio | Gerenciado pelo vendedor | Gerenciado pelo vendedor |
| Transportadoras parceiras  (Outras transportadoras serão adicionadas com o tempo.) | Transportadoras elegíveis: J&T, iMile, Estafeta, AMPM*Nota: as transportadoras são atribuídas automaticamente pela plataforma; os comerciantes não podem escolher as transportadoras.* | Os vendedores podem escolher entre transportadoras elegíveis, incluindo J&T Express, 99 Minutos, iMile, Estafeta, Qualitypost, Amazon Logistics, Mexico Post, DHL Express, Bigsmart, UPS, Redpack, Ivoy, Paquetexpress e FedEx. |
| Seleção da transportadora/velocidade de envio | O TikTok atribui automaticamente um serviço de envio. | Gerenciado pelo vendedor |
| Descontos de envio disponíveis | O TikTok oferece frete grátis para a maioria dos clientes no momento da finalização da compra \* | ~~O TikTok oferece descontos promocionais em pedidos elegíveis \*~~ |
| Obtenção da etiqueta de envio | Gerenciado pelo TikTok | Gerenciado pelo vendedor |
| Divisão de pedidos em pacotes separados | Disponível; requer ação do vendedor antes de agendar a coleta. O vendedor é responsável por quaisquer custos adicionais. \* | Disponível; requer ação do vendedor antes da impressão da etiqueta. O vendedor é responsável por quaisquer custos adicionais. \* |
| Combinação de vários pedidos em um único pacote | Disponível; requer ação do vendedor antes de agendar a coleta.\* | Disponível; requer ação do vendedor antes de agendar a coleta/entrega. \* |
| Envio do pedido (coleta ou entrega pela transportadora) | O vendedor deve garantir que a coleta seja feita pela transportadora em até 3 dias úteis após a realização do pedido. | O vendedor deve garantir que a coleta seja feita pela transportadora em até 3 dias úteis após a realização do pedido. |
| Carregamento de números de rastreio | O TikTok gera números de rastreio assim que as etiquetas são compradas com sucesso. | O vendedor carrega o número de rastreio, sendo permitida uma única edição em até 72 horas após o carregamento. |
| Gestão de devoluções/reembolsos (Aprovação/Rejeição) | Gerenciado pelo vendedor | Gerenciado pelo vendedor |
| Resgate de compensação do vendedor por problemas logísticos | O vendedor tem direito a compensação caso o comprador receba reembolso devido a problemas logísticos. | Não elegível para qualquer compensação do vendedor relacionada a problemas logísticos. |
| Serviço de atendimento ao cliente para compradores com problemas logísticos | Gerenciado pelo TikTok | Gerenciado pelo vendedor |

*\*Sujeito a alterações ou limitações.*

## Como se inscrever em cada opção de envio

Nota: por padrão, os novos vendedores são configurados na opção "Enviado pela plataforma". A opção "Enviado pelo vendedor" está disponível apenas para vendedores selecionados até novo aviso.  

* Na Central do vendedor TikTok Shop, acesse **Pedidos** > **Configurações de envio** > **Envio e entrega** para abrir a página **Opções de envio**.

**Notas importantes:**

1. Configuração da conta: a escolha entre "Enviado pelo vendedor" e "Enviado pela plataforma" é feita no nível da conta. Não é possível aplicar simultaneamente a opção "Enviado pelo vendedor" a alguns pedidos e "Enviado pela plataforma" a outros.
2. As alterações aplicam-se apenas a pedidos futuros: quaisquer alterações nas configurações de envio na Central do vendedor só serão aplicadas a pedidos recebidos após a alteração ser efetuada. Por exemplo, se você mudar de "Enviado pelo vendedor" para "Enviado pela plataforma" em 8 de novembro, todos os pedidos feitos antes de 8 de novembro ainda precisarão ser processados usando a opção "Enviado pelo vendedor".
