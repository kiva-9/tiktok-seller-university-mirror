## Visão geral

Este artigo ensinará como processar solicitações de amostra grátis de criadores. Isso envolve os **métodos de envio, remessa, embalagem, rastreio** e **pagamento** relacionados ao envio de amostras grátis para criadores.

Para saber mais sobre o processo de **aprovação e gerenciamento de solicitações de amostra grátis**, leia este artigo: [Guia de amostra grátis para vendedores](https://seller-br.tiktok.com/university/essay?knowledge_id=6589441682917136&identity=1 "https://seller-br.tiktok.com/university/essay?knowledge_id=6589441682917136&identity=1").

## Introdução aos métodos de envio de amostras grátis

1. **Enviado pelo vendedor**
   * Pedidos de amostra grátis com o método de envio definido como "Enviado pelo vendedor" não serão atribuídos automaticamente a um provedor de logística do TikTok Shop. Você deve organizar a entrega diretamente com a transportadora escolhida (garanta que seja uma transportadora recomendada pelo TikTok Shop).
   * **Transportadora recomendada:** os parceiros logísticos aceitos pelo TikTok Shop que os comerciantes podem selecionar são Correios, J&T Express, Loggi, Jadlog e iMile.
2. **Enviado pela plataforma**
   * Pedidos de amostra grátis com o método de envio definido como "Enviado pela plataforma" serão atribuídos automaticamente a um provedor de logística do TikTok Shop.
   * É **necessário carregar e anexar as faturas dos pedidos de amostra grátis**. Para obter mais informações sobre como processar o pedido, acesse [este guia](https://seller-br.tiktok.com/university/essay?knowledge_id=2915348630603521 "https://seller-br.tiktok.com/university/essay?knowledge_id=2915348630603521").

## **Conheça os métodos de envio de amostras grátis disponíveis**

Ao selecionar um método de envio, o sistema determina qual modo de envio será utilizado **com base nas Configurações de envio do vendedor**, incluindo se é possível emitir notas fiscais de bonificação (NF-e de bonificação) para recompensas ou amostras grátis.  
**O que é uma nota fiscal de bonificação ou sem cobrança?**Uma **nota fiscal de bonificação** refere-se à nota emitida para pedidos com valor de R$ 0, como brindes oferecidos no Recompensa da LIVE para clientes ou amostrasgrátis custeadas pelo vendedor, em conformidade com as regulamentações fiscais locais.  
Atualmente, existem duas formas de emitir **notas fiscais de bonificação**:  

1. O vendedor emite as NF-es por meio do seu próprio **sistema ERP**.
2. A nota fiscal é emitida pelo **recurso de emissão de NF-e do TikTok Shop** (emissão assistida pela plataforma). Saiba mais em [Emissão de NF-e no TikTok Shop](https://seller-br.tiktok.com/university/essay?identity=1&role=1&knowledge_id=4896169624913680&from=feature_guide "https://seller-br.tiktok.com/university/essay?identity=1&role=1&knowledge_id=4896169624913680&from=feature_guide").

### **Como Configurar/Alternar o Método de Envio**

Existem dois cenários para configurar o método de envio:  
**Alternância Automática**

* O sistema identificará dinamicamente os ERPs aos quais os vendedores estão conectados atualmente.
* Os vendedores que estiverem conectados a ERPs (incluindo novos vendedores) que **suportam notas fiscais de bonificação** serão automaticamente alternados para o **4PL** para pedidos gratuitos.
* Quando os vendedores **desvincularem** todos os ERPs que suportam notas fiscais de bonificação, seus métodos de envio para pedidos gratuitos serão convertidos automaticamente para **3PL**.

**Alternância Manual**

* Se o sistema não reconhecer que os vendedores se conectaram a ERPs que suportam notas fiscais de bonificação, os vendedores ainda deverão fazer a alternância manual.

### Como emitir uma nota fiscal de bonificação (NF-e de bonificação)?

Para comerciantes enquadrados no regime tributário "**Simples Nacional**", é possível emitir **NF-es** diretamente pelo **TikTok Shop** e carregá-las antes do envio. Para obter procedimentos detalhados de emissão de notas fiscais, consulte: [Emissão de NF-e no TikTok Shop](https://seller-br.tiktok.com/university/essay?identity=1&role=1&knowledge_id=4896169624913680&from=feature_guide "https://seller-br.tiktok.com/university/essay?identity=1&role=1&knowledge_id=4896169624913680&from=feature_guide").  
Para comerciantes que emitem notas fiscais por meio do próprio sistema ERP, é possível ativar a opção "**Enviado pela plataforma**" em **Configurações de envio de pedidos** antes da aprovação das amostras grátis. Para saber mais sobre o status da integração com o ERP e o suporte à emissão de notas fiscais para amostras grátis, acesse: [Central do vendedor → Aplicativos e agências → App Store → Planejamento de recursos empresariais](https://seller-br.tiktok.com/services/market?category_id=2986261&sort=3&page=1&dtc=&fromRecommendation=&urlBadges=7496702303774721793 "https://seller-br.tiktok.com/services/market?category_id=2986261&sort=3&page=1&dtc=&fromRecommendation=&urlBadges=7496702303774721793").

## Preparar o envio de amostras grátis

### Enviado pelo vendedor

**Etapa 1:** Filtre as tags de pedido "**Amostra grátis do vendedor**" e as tags de método de envio "**Enviado pelo vendedor**", selecione os pedidos que deseja processar na página Gerenciar pedidos e clique em "**Providenciar envio**".

|  |  |
| --- | --- |
| image | image |

**Etapa 2:** Obtenha informações de endereço dos pedidos.

* Exporte as informações dos pedidos a serem enviados clicando no botão "Exportar".
* Prepare os envios com os provedores de logística terceirizados de acordo com as informações de endereço dos pedidos.
* O modelo baixado incluirá ID do pedido, ID do SKU, quantidade e informações de envio do comprador, o que ajuda você a cumprir o envio com a transportadora mais rápido. É possível exportar até 200.000 pedidos de uma só vez.

|  |  |
| --- | --- |
| image | image |

**Etapa 3:** Adicione as informações de rastreio.

* Adicione informações de rastreio para os pedidos um a um.
  + Selecione pedidos em massa e clique no botão Adicionar informações de rastreio.
  + Copie e cole a ID de rastreio e a transportadora de cada pedido.
  + Clique em Enviar.

|  |  |
| --- | --- |
| image | image |

* Adicione informações de rastreio para pedidos em massa.
  + Clique em Baixar modelo. Carregue as informações de envio dos seus pedidos.

* Revise as folhas de "Definições de dados" e "Exemplos" no modelo antes de preencher o arquivo para se familiarizar com as informações que irão para o seu arquivo.
* O sistema redirecionará você para a página Adicionar informações de rastreio, onde poderá inserir a ID de rastreio e selecionar a transportadora. Quando terminar, clique em "Enviar pacote".

## Pagamento dos custos de entrega da opção Enviado pela plataforma

* Um botão **Ver faturas** foi adicionado ao canto superior direito da página **Solicitação de amostra**. Clique nesse botão para abrir a página **Faturas**.
* Clique em **Ver pedido** na página **Faturas** para voltar à Central de afiliados e exibir as informações solicitadas relacionadas à ID do pacote.
* O custo de entrega é cobrado por cada ID de pacote e debitado de suas liquidações. O ciclo de faturamento é diário.
* Os vendedores que estão em áreas com custos de entrega serão adicionados à lista restrita de entrega e impedidos de usar a opção **Enviado pela plataforma** para entregar amostras.
