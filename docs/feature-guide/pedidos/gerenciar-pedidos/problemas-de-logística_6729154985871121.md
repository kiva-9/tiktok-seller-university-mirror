# **Visão Geral**

Este artigo explora diversos tipos de problemas de logística que podem ocorrer durante o seu processo de envio. Ao aprender sobre isso, você conseguirá entender os problemas que podem acontecer e como resolvê-los, para que você possa atender e enviar seus pedidos dentro do prazo.

## **O que são problemas de logística?**

Na página **"Gerenciar pedidos"** em "Central do vendedor", você pode filtrar pedidos com problemas de logística, o que permite identificar e tratar prontamente quaisquer problemas. Isso ajuda a evitar atrasos ou possíveis perdas em seu processo de envio.

## **Tipos de problemas de logística**

Categorizamos os status anormais de pacote em diferentes tipos. Se os seus pedidos tiverem problemas de logística,um alerta em vermelho será mostrado nos detalhes do seu pedido.

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/714289a1e5cf4a36a83569d15e64d04c~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059593367&x-signature=%2FHMc2rp0dgB9mgSLCtSTDuAtZ3o%3D)

Abaixo estão os diferentes tipos de problemas de logística:

|  |  |  |  |
| --- | --- | --- | --- |
| Tipo de pacote anormal | Descrição | Orientação | Captura de tela |
| Falha ao enviar o pacote | O pacote não pode ser enviado devido a problemas de sistema ou restrições da transportadora. É importante deixar claro que isso não é culpa do vendedor. Por exemplo, isso acontece quando a transportadora não consegue verificar o endereço de envio do comprador. | Entre em contato com o comprador para informá-lo sobre o problema e recomende considerar cancelar o pedido devido à discrepância de endereço. | image |
| Etiqueta rejeitada | A criação da etiqueta falhou devido a problemas do sistema, como falha na verificação do endereço do depósito do vendedor. Esses casos podem ser resolvidos e as etiquetas podem ser geradas novamente para os pedidos. | Siga as orientações da plataforma para resolver o problema e gerar novamente a etiqueta na página de etiquetas de envio. |  |
| Dados de rastreamento não encontrados | Este cenário só acontece depois que os pedidos **"Enviado pelo vendedor"** tiveram seu ID de rastreamento carregado, e a plataforma não detecta nenhuma atualização de rastreamento para esse ID em 24 horas. | A plataforma orienta os vendedores a verificar o formato de identificação de rastreamento e consultar atualizações no site oficial da transportadora, em seguida, editar prontamente o ID de rastreamento. |  |
| Incompatibilidade do fornecedor de logística | Esta situação ocorre apenas depois que os pedidos **"Enviado pelo vendedor"** têm o seu ID de rastreamento carregado. Após 24 horas, a plataforma detecta uma discrepância em que a transportadora informada pelo vendedor não corresponde à identificada pela plataforma. | A plataforma enviará um lembrete ao vendedor para verificar novamente as informações da transportadora, e oferecerá uma sugestão da transportadora. O vendedor pode decidir se deve fazer quaisquer alterações necessárias. |  |
| Devolvido à transportadora | O pacote não foi entregue e será devolvido ao vendedor. | * Entre em contato com o comprador para solicitar um reembolso.  Caso não tenha recebido o pacote dentro 20 dias após a devolução e já tenha aprovado a solicitação de reembolso, você pode abrir um chamado para solicitar compensação. Uma vez confirmada, a compensação pela perda será fornecida. | image |
| Falha na entrega ao comprador | O pacote não foi entregue. | * Recomende que o comprador verifique se o endereço de envio está correto e confira o status do pacote. * Se o comprador rejeitar o pacote, oriente-o a solicitar um reembolso e aprove prontamente a solicitação. * Em caso de falha na entrega, o pacote será devolvido a você. Você pode acompanhar isso através das atualizações de status do pacote. | image |
| Devolução ao vendedor | O pacote foi devolvido ao vendedor e entregue com sucesso. | * Notifique o comprador sobre o pedido foi cancelado e reembolsado. Ele pode verificar o status do reembolso no app TikTok.  Se o status de entrega estiver incorreto, você pode abrir um chamado para verificar o status do pacote. O suporte ao cliente do TikTok Shop compensará a perda após a confirmação da reivindicação. | image |
| Pacote extraviado | O pacote foi perdido e o pedido será cancelado em 48 horas, resultando em um reembolso para o comprador. O TikTok Shop oferecerá uma compensação pela perda. | Caso você não receba o reembolso dentro 5 dias úteis, abra um chamado para nossa investigação. | image |
| Pacote danificado | O pacote foi danificado e o pedido será cancelado em 48 horas, resultando em um reembolso para o comprador. O TikTok Shop oferecerá uma compensação pela perda. | Caso você não receba o reembolso no prazo de 5 dias úteis, abra um chamado para nossa investigação. | image |
| Pacote descartado | A transportadora descartou o pacote, porque o destinatário não estava disponível. | * O TikTok Shop iniciará o processo de reembolso, uma vez que não foi possível devolver o pacote a você. Responda ao comprador prontamente. * Entre em contato com o suporte do TikTok Shop para obter assistência. | image |
| O comprador relatou atraso no trânsito | O pacote foi coletado pela transportadora. Apesar de não exceder o tempo estimado de entrega, o comprador reclamou sobre o atraso do envio. | * Atualize ao cliente sobre o tempo estimado de entrega para gerenciar sua expectativa. * Se o cliente reclamar sobre o atraso no envio, iniciando uma solicitação pós-venda, sugira que considere cancelar a solicitação pós-venda e dar tempo para a chegada do pacote. Como alternativa, o comprador pode rejeitar o pacote após o recebimento ou solicitar uma devolução em uma fase posterior se não tiver interesse em ficar com o pacote. |  |
| Comprador relatou atraso na entrega | O pacote ainda não foi entregue e o tempo estimado de entrega foi excedido. | * Mantenha o cliente informado sobre a atualização da data estimada de entrega para gerenciar sua expectativa. * Aconselhe o cliente a considerar a rejeição do pacote no momento do recebimento ou solicitar uma devolução em uma fase posterior se não desejar ficar com o pacote. * Abra um chamado para verificar o status do pacote para investigação. |  |
| Pacote preso em trânsito | O pacote ficou parada no transporte por um período prolongado. | * Mantenha o cliente informado sobre a atualização da data estimada de entrega e oriente-o a aguardar. Como alternativa, sugira que o comprador considere fazer uma solicitação pós-venda. * Abra um chamado para verificar o status do pacote. * O chamado será processado dentro 72 horas. Caso haja confirmação de que o pacote foi danificado ou perdido, você pode entrar em contato com o comprador para solicitar um reembolso. |  |
| Atraso na entrega do pacote | O pacote está em trânsito e o tempo estimado de entrega (ETA) foi excedido. | * Peça ao comprador que inicie uma solicitação de reembolso e essa solicitação será aprovada pela plataforma. * A plataforma iniciará uma investigação com a transportadora e decidirá se o reembolso ao vendedor é necessário no prazo de **72 horas.** * Incentive o vendedor a abrir um chamado para iniciar a investigação com a transportadora. |  |
