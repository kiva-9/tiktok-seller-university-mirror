## **1.2：Como calcular o peso faturado**

O custo de envio final é determinado pelo **peso faturado**. O peso faturado é o **valor máximo** entre as quatro medições a seguir:  

|  |  |  |  |
| --- | --- | --- | --- |
| **O peso faturado é o máximo destes quatro valores:** | | | |
| **Peso declarado pelo vendedor** | **Peso cubado com base nas dimensões declaradas pelo vendedor** | **Peso medido pela transportadora** | **Peso cubado medido pela transportadora** |
| O peso do produto inserido na Central do vendedor TikTok Shop (página "Gerenciar produtos"). | Calculado com base nas dimensões do pacote inseridas na página "Gerenciar produtos".**Fórmula:** (Comprimento [cm]× Largura [cm] × Altura [cm]) / 6.000 | O peso real do pacote final conforme medido pela logística da transportadora. | O peso cubado do pacote final conforme medido pela logística da transportadora.**Fórmula:** (Comprimento [cm]× Largura [cm] × Altura [cm]) / 6.000 |

**O que é peso cubado?** O peso cubado (ou peso volumétrico) reflete a densidade de um pacote. É usado para itens leves, porém volumosos. Por exemplo, uma caixa grande de travesseiros pode ser muito leve, mas ocupa bastante espaço em um caminhão de entrega. O cálculo do peso cubado ajuda as transportadoras a cobrar de maneira justa pelo espaço que um pacote ocupa.

## **1.3：Quando as taxas de envio são cobradas?**

As taxas de envio são cobradas do vendedor assim que o status do pedido é atualizado para "Entregue".  

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **Status da logística** | Enviado (RTS) | Coletado | Em trânsito | **Entregue** |
| **Taxa cobrada** |  |  |  | ✅ |

> A plataforma só descontará a taxa de envio depois que o pacote for entregue com sucesso ao cliente.

# **2.Cenários comuns e exemplos**

Confira alguns exemplos comuns para entender como o peso tarifado afeta a taxa de envio final.  
**Exemplo 1: quando o peso cubado é maior do que o peso real****P:** Minha vara de pesca pesa 4 kg, então por que me cobraram por uma remessa de 4,88 kg?**A:** A taxa de envio se baseou no **peso cubado** do pacote, pois o peso cubado era maior do que o peso real.

|  |  |
| --- | --- |
| **Produto** | Vara de pesca |
| **Peso real inserido pelo vendedor** | 4 kg |
| **Dimensões inseridas pelo vendedor** | 15 cm × 15 cm × 130 cm |
| **Peso cubado calculado** | (15 × 15 × 130) / 6.000 = **4,88 kg** |

**Exemplo 2: quando o peso e as dimensões do pacote não são incluídos****P:** Meu copo de vidro pesa apenas 0,5 kg, porém a taxa de envio foi calculada para 1,33 kg. Por quê?**R:** É preciso considerar o peso e as dimensões de **todos os materiais da embalagem**, incluindo plástico bolha, caixas e outros materiais de reforço.

|  |  |
| --- | --- |
| **Produto** | Copo de vidro |
| **Peso real inserido pelo vendedor** | 0,5 kg |
| **Dimensões apenas do produto** | 15 cm × 15 cm × 20 cm |
| **Peso cubado apenas do produto** | (15 × 15 × 20) / 6.000 = 0,75 kg |
| **Dimensões com embalagem reforçada** | 20 cm × 20 cm × 25 cm |
| **Peso cubado final com embalagem** | (20 × 20 × 25) / 6.000 = **1,33 kg** |

**Exemplo 3: quando a embalagem é superdimensionada****P:** Meu smartwatch é pequeno e pesa 0,3 kg. Por que me cobraram por um pacote de 1,33 kg?**R:** O uso de uma caixa muito maior do que o item pode aumentar bastante o peso cubado. Use sempre uma embalagem que acondicione seu produto sem deixar muito espaço vazio.

|  |  |
| --- | --- |
| **Produto** | Smartwatch |
| **Peso real inserido pelo vendedor** | 0,3 kg |
| **Dimensões apenas do produto** | 5 cm × 5 cm × 3 cm (Peso cubado: 0,015 kg) |
| **Caixa superdimensionada usada para envio** | 20 cm × 20 cm × 25 cm |
| **Peso cubado da caixa** | (20 × 20 × 25) / 6.000 = **1,33 kg** |

**Exemplo 4: quando há discrepância entre os dados do vendedor e da transportadora****P:** Meu casaco acolchoado pesa 5 kg, e o peso cubado dele é de 6,67 kg. Por que o peso final faturado foi de 16,67 kg?**R:** A plataforma usa o **peso máximo registrado** por você ou pela transportadora. Nesse caso, o peso cubado do pacote medido pela transportadora foi o valor mais alto.

|  |  |
| --- | --- |
| **Produto** | Casaco acolchoado |
| **Peso real inserido pelo vendedor** | 5 kg |
| **Peso cubado inserido pelo vendedor** | (50 × 40 × 20) / 6.000 = 6,67 kg |
| **Peso real medido pela transportadora** | 10 kg |
| **Peso cubado medido pela transportadora** | (50 × 50 × 40) / 6.000 = **16,67 kg** |
