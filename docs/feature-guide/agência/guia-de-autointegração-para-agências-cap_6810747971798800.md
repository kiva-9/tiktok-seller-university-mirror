# **Guia de autointegração para agências CAP**

Este guia explica como Parceiras de Agência de Criação (CAP) podem se integrar à Central de parceiros do TikTok Shop e estabelecer relações de longo prazo com criadores para apoiá-los na produção de um conteúdo cativante, incluindo vídeos curtos e LIVEs no TikTok.

Para começar, abordaremos os seguintes tópicos:

* Requisitos de integração
* Gerenciamento de parcerias com criadores

# **Gerenciamento de parcerias com criadores**

O papel principal de uma CAP é o gerenciamento de criadores. Isso envolve o desenvolvimento e o suporte aos criadores para que produzam vídeos curtos e conteúdo de e-commerce ao vivo (LIVEs) dentro do ecossistema do TikTok Shop. Para facilitar isso, as CAPs podem usar o recurso **Gerenciar parcerias** para se conectar a criadores, vincular contas, configurar o gerenciamento de taxas e estabelecer colaborações de longo prazo.

## **Como conectar-se a novos criadores**

1. Navegue até[Central de parceiros > Criadores > Gerenciar parcerias](https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=all "https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=all")

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/be4350418fed46e3ab5c0164f4c22bf4~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060181128&x-signature=zdLN9G0BEoL7Xgx%2B%2BnQ7LLeP4tU%3D)

|  |  |
| --- | --- |
| 1. Clique em[Adicionar novo criador](https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=all "https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=all")e preencha as informações obrigatórias:    * **Nome do criador**    * **Data de expiração do link**: isso permite que você veja os dados dos criadores e apresente estratégias para melhoria. Também ajuda a gerenciar acordos de taxas.    * **Acordo de taxas**: serve para determinar a divisão da comissão entre você e os criadores. Quando um criador ganhar uma comissão, uma parte dela será creditada a você com base nos termos acordados.   ***Observação:***   * *Para vincular pela primeira vez, a data máxima de expiração do link é de dois meses. Após esse período, você pode vincular novamente ao mesmo criador por até um ano.* * *O acordo da taxas de divisão da comissão pode ser fixado em 0%.* * *As alterações no acordo de taxas de comissão podem ser iniciadas após você ter se vinculado com o criador, mas isso deve ser confirmado pelos criadores.* | image |

2. Adicione o perfil da sua conta no TikTok (opcional) para oferecer aos criadores informações sobre sua empresa.
3. O criador receberá uma solicitação de vinculação e deverá aprová-la ou recusá-la por meio do aplicativo TikTok dentro de sete dias. Se nenhuma ação for tomada, será necessário reenviar a solicitação.

## **Gerenciamento do status de vinculação**

Você pode acompanhar os status de vinculação no recurso **Gerenciar parcerias**. As guias a seguir apresentam insights detalhados:

|  |  |
| --- | --- |
| **Nome da guia** | **Descrição** |
| Todos | Exibe todas as relações de vinculação. |
| Vinculados | Mostra criadores que aceitaram sua solicitação. Você pode ver os dados deles e as datas de expiração do link. |
| Não vinculados | Exibe os criadores que recusaram ou não vincularam e as solicitações que expiraram. |
| Link solicitado | Lista as solicitações pendentes. Os criadores têm sete dias para aceitar ou recusar essas solicitações. |
| Desvinculação solicitada | Mostra solicitações de desvinculação iniciadas por você ou pelos criadores. |
| A expirar | Exibe links próximos da data de expiração. Você também pode usar esta guia para enviar solicitações de extensão. |

## **Extensão de solicitações de vinculação**

1. Você pode gerenciar solicitações de vinculação que estão se aproximando da data de expiração em [Central de parceiros > Criadores > Gerenciar parcerias > A expirar](https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=binding_expire_soon&sub_tab=expiring_30_days "https://partner.eu.tiktokshop.com/affiliate-creator/binding-creator?market=14&tab=binding_expire_soon&sub_tab=expiring_30_days")
2. Você pode visualizar todas as solicitações de vinculação que vão expirar nos próximos 30 dias.

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/645be926da6d488cae6d4191bf38f544~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060181128&x-signature=c9k7oF9r%2BG7mtxfofg88PwBp354%3D)
3. Se você quer continuar o relacionamento com seu criador, clique em **Estender** e selecione uma nova duração (até um ano).

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/179fa35db171464db8bef02a7e406a6b~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060181119&x-signature=fqRIAvigiEHCLIdr%2FxbJkYiJl3w%3D)
4. O criador receberá a solicitação de extensão e poderá optar por aceitá-la ou recusá-la.
