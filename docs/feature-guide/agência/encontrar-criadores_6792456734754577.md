Este guia mostra como os Parceiros de Agência de Criadores (CAP) e os Parceiros de Afiliados do TikTok Shop (TAP) podem desbloquear infinitas oportunidades de colaboração através da página **Encontrar Criadores**. Conecte-se facilmente com uma vasta rede de criadores talentosos, refine sua busca com filtros poderosos e encontre os parceiros ideais para colaborar.  

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/cb8be94ad49a4446aa462c87ce166813~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155820&x-signature=OToQszXJD3tmyMU%2BYGvBavtdIdo%3D)

## **Vantagens de usar o Encontrar Criadores**

* Conecte-se com a ampla rede de criadores do TikTok com facilidade.
* Acesse informações de contato dos criadores e envie convites com apenas um clique.
* Refine sua busca com filtros como número de seguidores e métricas de desempenho.

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/2d0cf8d92c034e6b8a4934d79e7375ac~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155820&x-signature=KTqmkn0SHfTPGXzHgrZxlT12YJ4%3D)

## **Como usar o Encontrar Criadores？**

1. Acesse o Partner Center do TikTok Shop e vá até **Criadores > Encontrar Criadores.**

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/aba2c4e92b9c416e86bbe84daed55abc~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155821&x-signature=61DVBr6VctXvhfD%2BxOvdngGCiRY%3D)
2. Use os filtros disponíveis para refinar sua busca. As opções incluem:

* **Criadores**
  + Tipo de conteúdo
  + Categoria de produto
  + Comissão média
  + Agência do criador
  + Número de seguidores
  + Crescimento rápido

    ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/969556c0857148bfbf4db50fce9123dc~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155819&x-signature=bz0MbkOHffCmEVHHJCoY8sQmnDw%3D)
* **Seguidores**
  + Faixa etária
  + Gênero

    ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/42d07b030eeb4c9e82b41ecfbb7528ab~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155820&x-signature=g7%2FAGleto9dz9cZ9ZNU77ki9fiU%3D)
* **Desempanho**
  + Marcas parceiras
  + GMV
  + Unidades vendidas
  + Visualizações médias de vídeos EC
  + Visualizações médias de todos os vídeos
  + Engajamento (todos os vídeos)
  + Engajamento (vídeos EC)
  + Visualizações médias em live
  + Visualizações médias em EC live

    ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/f8e2d5068bb74335aa0c799e95a5c9de~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155820&x-signature=9zXdVsRc5ntwYhH9%2BQRESmVYnbQ%3D)

***Observação: Se não aparecerem criadores em alguns filtros, é possível que eles não tenham autorizado o compartilhamento desses dados.***

3. Após aplicar os filtros, clique no criador para ver o perfil completo, incluindo dados de contato e métricas de desempenho. Use essas informações para escolher os melhores parceiros.

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/6b114fff6ef34902a6890bd596383c77~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155825&x-signature=v%2F2VmQjgrWnkVvskHMtNcXnm2mk%3D)

   ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/210e5a4b10124bd6ae0a1d70c1f8b389~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155822&x-signature=smHtjLdk7KJeMfaUaYsBnRK8zEA%3D)
4. Depois de selecionar um criador, você poderá:

(a) Clicar em **“Convidar”** para enviar um convite individual.  
Preencha os seguintes campos:  

* **Objetivo do convite:**
* Para CAP: selecione “Estabelecer uma parceria de longo prazo com o criador.”
* Para TAP: selecione “Convidar o criador para divulgar produtos.”
* **Mensagem para o criador:** escreva uma breve apresentação (máx. 500 caracteres), destacando os benefícios de colaborar com sua agência.
* **Informações de contato:** adicione opções como WhatsApp, e-mail e número de telefone.![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/265dde8027ce4e17ad93e0cc46d49201~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155821&x-signature=N1dxTq0%2B80%2BDJKA2sdFPqIcyDo8%3D)![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/7967202a04904b6d8149156519cd5ac2~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155820&x-signature=oo9qFv%2BJQHQDA5Wwmqu1kv5Y2rs%3D)

Após o envio, CAPs e TAPs poderão acompanhar o histórico de convites.  
![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/2482c9c765ce417d85ec7d3046f351c1~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155819&x-signature=2%2BCTOPmintTQEsxwH787zZ3A8ko%3D)![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/0abd3065441b4713af60a56c20387785~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155819&x-signature=JaxigDz42QRRVBMxFoS36b9jRSg%3D)(b) Clicar no ícone "♡" para salvar o criador em uma pasta.  

* No canto superior direito, clique em **“Criadores Salvos”** para visualizar os criadores salvos.

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/c143cf5580bd45aa9b70d2439d0e1f24~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2060155819&x-signature=7ZME%2F7x1vnkSfV0iOMn7CAOHBK4%3D)

* Clique em **"Batch Invite"** para convidar vários creators de uma só vez.
* Preencha as informações necessárias, da mesma forma que ao convidar um creator individual no passo 4(a).

(c) Enviar mensagem via TTSPC Instant Messaging.

## FAQ

1. **Por que não consigo ver os dados de contato de alguns criadores?**

Os criadores podem optar por ocultar suas informações de contato. Se fizerem isso, elas não aparecerão na página Encontrar Criadores.  

2. **Existe um limite de convites por dia?**

Sim. CAPs podem enviar até **100 convites por dia** para criadores.
