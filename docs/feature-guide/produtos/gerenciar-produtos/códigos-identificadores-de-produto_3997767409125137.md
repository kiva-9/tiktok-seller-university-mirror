# **Códigos identificadores de produto**

**O que são códigos identificadores de produtos?**

Para a maioria das categorias, é necessário associar seus produtos a identificadores de produtos padrão do setor para criar novas páginas de produtos e anunciar no TikTok Shop.

Os códigos identificadores de produtos fazem parte de um sistema de identificadores exclusivos chamados GTINs (Global Trade Item Numbers, ou números de item de comércio global). Os GTINs usados com mais frequência são os UPCs (Universal Product Codes, códigos universais de produto), ISBNs (International Standard Book Numbers, números padronizados internacionais para livros) e EANs (European Article Numbers, números europeus para artigos). O código identificador de produto preenchido deve estar registrado no banco de dados GS1.

# **Como encontrar um código identificador de produto?**

Procure por GTIN, UPC, ISBNs ou EANs acima ou abaixo do código de barras na embalagem (ou cobertura) do seu produto. O GTIN-14 aparece no contêiner de envio.

| --- | --- |
| **ISBN**  *13 dígitos e o último dígito permite a entrada X (maiúsculo).* | image |
| **UPC**  *12 dígitos, apenas números;* | image |
| **EAN**  *8, 13, 14 dígitos, apenas números;* | image |
| **GTIN-14 (chamado de GTIN)**  *14 dígitos, apenas números;* | image |

# **Onde usar os códigos identificadores de produtos?**

Ao adicionar um novo anúncio de produto na Central do vendedor TikTok Shop, o campo do código identificador de produto está localizado na seção "Lista de Variações". No momento, esse campo é uma entrada opcional para todos os vendedores. Você pode pular esse campo se não tiver um código identificador.

Se estiver usando a Ferramenta de Lote, insira o código identificador do produto no campo **product\_identifier\_code**.

Se você é um usuário de API, pode usar a propriedade **identifier\_code & identifier\_code\_type** para gerenciar o código.

Quando o código identificador do produto da variação é enviado, ele não pode mais ser modificado ou alterado.

# **Como inserir um código identificador de produto?**

* Para cada variação, selecione o tipo de código identificador do produto (por exemplo, GTIN/EAN/UPC/ISBN)
* Depois que o tipo for selecionado, a entrada deve corresponder ao formato desse tipo de código (por exemplo, 14 dígitos para o tipo GTIN). Um código de erro será exibido se o campo for deixado em branco, não corresponder ao formato ou tiver duplicatas (cada variação deve ter um código identificador de produto exclusivo)
* Uma vez preenchido este campo, os outros campos obrigatórios devem ser preenchidos antes de atualizar os anúncios.
* Se o SKU do produto contiver vários itens combinados, insira os IDs adicionais neste campo. Você pode adicionar até 10 IDs e separá-los com vírgulas.

# **Obter um código identificador de produto**

Se você não tiver um ID de produto para o seu item, poderá solicitá-lo ao fabricante. Se o produto for de fabricação própria, visite o [site de padrões GS1](https://www.gs1.org/standards/get-barcodes "https://www.gs1.org/standards/get-barcodes") para mais informações.
