## **Adicionar informações de contato**

Fornecer suas informações de contato no TikTok Shop pode aumentar sua visibilidade junto aos Vendedores. Esses Vendedores podem entrar em contato com você diretamente para possíveis parcerias e colaborações. Além disso, o TikTok Shop pode fornecer dicas e truques sobre o próprio app para levar você ao sucesso.

Veja a seguir um guia passo a passo rápido. Toque na imagem para ampliá-la:

|  |  |  |  |
| --- | --- | --- | --- |
| image | image | image | image |
| Entre na Central de criadores do TikTok Shop e toque no botão com três linhas | Você será redirecionado para Configurações. Aqui, você tocará em **Suas informações de contato** | Registre suas informações de contato tocando nas setas | Toque em **Atualizar** para confirmar suas informações |

## **Gerenciamento das informações de contato**

### **Configurações de privacidade**

Gerencie quais vendedores podem ver suas informações pessoais de contato. Somente os vendedores nas categorias selecionadas terão acesso às suas informações pessoais de contato para discutir as oportunidades de colaboração.

Você também pode escolher quais informações de contato dos vendedores podem ver:

|  |  |  |  |
| --- | --- | --- | --- |
| image | image | image | image |
| Entre na Central de criadores do TikTok Shop e toque no botão com três linhas | Você será redirecionado para as Configurações. Aqui, você tocará em **Suas informações de contato** | Toque no botão no canto superior direito para ter acesso às **Configurações de visibilidade** | Você pode selecionar quais informações de contato estarão **Visíveis, Visíveis para Selecionados** ou **Invisíveis** |

Observação: **Visíveis para parceiro** não oferece suporte à exibição parcial. Você só poderá escolher **Visíveis para todos** ou **Não visíveis**.
