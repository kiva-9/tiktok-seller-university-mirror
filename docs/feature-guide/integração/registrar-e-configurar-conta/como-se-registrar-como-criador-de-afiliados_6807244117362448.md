Está interessado em ingressar no TikTok Shop como Criador? Quer usar sua conta e obter ganhos por comissão? Este artigo ensinará você a se registrar como Criador usando o aplicativo TikTok.

Confira estas duas etapas simples para começar.

## **Etapa 1: Entre por meio do seu Perfil**

Criar sua conta de Criador pode ser feito dentro do aplicativo TikTok. Use a conta existente e siga as etapas abaixo para saber onde se inscrever.

|  |  |  |
| --- | --- | --- |
| image | image | image |
| 1. Abra o aplicativo TikTok, acesse seu Perfil e toque nas três linhas | 2. Toque em **TikTok Studio** | 3. Toque em **TikTok Shop para criadores** |

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/99a23400601f4fb3813b15f9d5c34038~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059646172&x-signature=sSDozDsiH5e0R0WXO7x4R3S9hMU%3D)

## **Etapa 2: Verificar requisitos e registre-se**

A próxima etapa consiste em verificar se sua conta atende aos requisitos necessários para a inscrição. Complete a lista de verificação fornecida para iniciar a jornada como Criador do TikTok Shop.

|  |  |  |
| --- | --- | --- |
| image.png | image | image |
| 4. Você verá uma lista dos requisitos necessários para qualificar-se para a inscrição. **Toque em Inscrever-se** | 5. Agora, você se inscreveu para ser um Criador! Sua inscrição será analisada e você receberá uma notificação assim que ela for concluída. | 6. Quando você receber uma notificação, agora você é oficialmente um Criador! |

## **Etapa 3: Verificar sua identidade**

Depois que a inscrição for aprovada, você precisará verificar sua identidade fazendo o upload de uma **ID de foto válida** e as **informações fiscais** no **Centro de verificação**. Para ganhar e sacar a comissão pelo seu conteúdo, você precisará concluir a verificação.

|  |  |  |
| --- | --- | --- |
| image   7. Se você for um novo usuário, receberá este pop-up quando acessar pela primeira vez a Central de criadores. Toque em **Verificar** | image   8. Ao tocar em **Verificar**, você será redirecionado para o **Centro de verificação**. Aqui, você preencherá sua identidade e as informações fiscais | image   9. Depois que suas informações forem adicionadas, o sistema as analisará e, após serem aprovadas, você poderá começar a ganhar no TikTok Shop! |

## **Perguntas frequentes**

1. Posso me registre como Criador e Vendedor?
   * Sim. Como criador do TikTok Shop, você estará qualificado para se registrar como Vendedor se atender aos requisitos. Não há nenhuma restrição para ser um Criador ou Vendedor. Você só precisa atender aos critérios da plataforma.
2. E se eu atender a todos os requisitos e minha inscrição não for aprovada?
   * Você pode abrir um tíquete para solicitar que investiguemos.
