# O que é o Programa de Assinatura?

O Programa de Assinatura é um modelo de compra que permite aos clientes assinar produtos que compram regularmente. Após a assinatura, a plataforma processa automaticamente pedidos recorrentes na frequência escolhida pelo cliente, que aproveita um desconto exclusivo de assinatura definido por você, o vendedor.  
Este recurso é especialmente adequado para **categorias de bens de consumo de giro rápido**, tais como:  

* Saúde e bem-estar
* Beleza e cuidados pessoais
* Alimentos e bebidas
* Produtos para animais de estimação
* Itens essenciais para o lar

Ao fazer uma assinatura, o cliente seleciona o **produto de sua preferência, a frequência de entrega e a quantidade**. A plataforma então processa, no prazo — sem necessidade de qualquer ação por parte do comprador a cada ciclo.

# Como configurar o Programa de Assinatura

**Elegibilidade:** atualmente, apenas vendedores inscritos no programa **SFP (Programa de Taxa de Envio)** são elegíveis para ativar o Programa de Assinatura. Isso garante que os assinantes aproveitem os descontos de frete disponibilizados pelo programa.  

## Etapa 1 — Acesse as configurações de assinatura

1. Faça login na **Central do vendedor**.
2. Acesse Produto > Gerenciar Produto.
3. Selecione os produtos que deseja habilitar para assinatura, clique em "..." para abrir o menu suspenso e localize a opção de configurar a assinatura.
4. Ative a assinatura do produto.

## Etapa 2 — Configure o desconto da assinatura

Você precisa definir o seguinte para cada produto (ou lote de produtos):  

|  |  |  |
| --- | --- | --- |
| **Configuração** | **Descrição** | **Opções** |
| **Desconto regular** | O desconto contínuo de assinatura é aplicado a todos os pedidos recorrentes após o primeiro. | Escolha entre faixas fixas: **5%, 10%, 15% ou 20% de desconto** |
| **Desconto de primeiro pedido** | Um desconto de boas-vindas especial para o primeiro pedido do assinante, para incentivar a adesão. | Valor personalizado com desconto entre **5% e 90%**. Deve ser igual ou superior ao Desconto Regular. |
| **Frequência da assinatura** | Cadência de entrega sugerida exibida aos compradores. Se não for definida, o sistema exibe uma recomendação padrão. | A cada 1, 2, 3, 4, 5, 6, 7 ou 8 semanas — ou a cada 3, 4, 5 ou 6 meses |

# Como pausar ou cancelar (desativar) o Programa de Assinatura

Se você precisar parar de oferecer assinaturas para um produto, tem duas opções:  

|  |  |  |
| --- | --- | --- |
| **Ação** | **O que faz** | **Impacto nos assinantes existentes** |
| **Pausar** | Impede que novos clientes assinem este produto. A opção de assinatura fica oculta na página do produto. | **Nenhum impacto** — todos os assinantes atuais continuam recebendo seus pedidos recorrentes com o mesmo desconto. |
| **Desativar** | Cancela totalmente a assinatura deste produto, encerrando todas as assinaturas ativas. | **Todas as assinaturas existentes são canceladas.** Os assinantes serão notificados de que a assinatura terminou. |

**Importante:** antes de desativar, o sistema exibirá o **impacto estimado na receita** (perda projetada de GMV decorrente do cancelamento de assinaturas ativas). Revise cuidadosamente antes de confirmar. Recomendamos usar a opção **Pausar** primeiro, caso você queira apenas interromper novas assinaturas e, ao mesmo tempo, manter as assinaturas existentes.  

## Etapas para pausar ou desativar

1. Acesse a **Central do Vendedor** → **Promoções** (ou **Gerenciamento de produtos**).
2. Filtre por produtos com assinatura disponível.
3. Selecione o(s) produto(s) que deseja modificar.
4. Escolha **Pausar** ou **Desativar**:
   * **Pausar:** confirme para fechar a entrada de novos assinantes. Os pedidos existentes permanecem em vigor.
   * **Desativar:** analise o pop-up de perda estimada e, em seguida, confirme para encerrar todas as assinaturas.
5. Se você pausou um produto e deseja reativar as assinaturas mais tarde, basta reativar a assinatura — ela reaparecerá na página do produto para novos clientes.

# Lógica de preços e descontos

Entenda como a precificação de assinaturas funciona em conjunto com outras promoções:  
O preço pago pelo assinante é calculado nesta ordem:  

1. **Preço base do produto** (após qualquer desconto de campanha ou promoção em vigor)
2. **→ Desconto de assinatura** aplicado adicionalmente
3. **→ Cupons elegíveis** aplicados automaticamente a partir da conta do comprador

Isso significa que, durante campanhas da plataforma (como grandes promoções), o desconto da assinatura é **cumulativo** com os preços promocionais, proporcionando aos assinantes uma economia ainda maior.  
**Dica para períodos de campanha:** como os descontos de assinatura podem ser acumulados com os preços de campanhas promocionais, planeje com cuidado as ofertas que você submeterá, para garantir a manutenção de margens saudáveis. Considere entrar em contato com seu gerente de contas antes de grandes eventos de vendas.  

## **Lógica de aplicação de descontos para assinaturas existentes**

Quando um vendedor altera o desconto de assinatura de um produto, o sistema sempre aplica o **desconto maior (mais vantajoso) aos assinantes existentes**, a fim de proteger a experiência do consumidor. Especificamente:  

* **Aumentar o desconto (por exemplo, de 10% para 20%):** o novo desconto de 20% aplica-se **tanto às assinaturas existentes quanto às novas**.
* **Redução do desconto (p. ex., 20% → 10%):** o novo desconto de 10% aplica-se **apenas a novas assinaturas**; os assinantes atuais mantêm o desconto original de **20%**.

**Implicação fundamental para os vendedores:** uma redução no desconto nunca pode ser repassada aos assinantes ativos. Se um vendedor realmente quiser reduzir o desconto de assinaturas existentes, ele deve **encerrar (desativar) essas assinaturas e configurá-las novamente** com a nova taxa, mais baixa.

# **Sem Estoque no programa de assinatura**

Se um produto de assinatura estiver sem estoque quando chegar a data do próximo pedido, o sistema não fará o pedido imediatamente. O comprador receberá uma notificação por e-mail, e o sistema tentará fazer o pedido automaticamente por até **3 dias**.  
Os vendedores não precisam acionar a nova tentativa manualmente, mas devem repor o estoque do produto o mais rápido possível dentro dessa janela de 3 dias. Se o estoque voltar a ficar disponível durante esse período, o pedido de assinatura poderá ser feito automaticamente.  
Se o produto ainda estiver sem estoque após 3 dias, pularemos o pedido de renovação de assinatura automaticamente. Esse período de nova tentativa é limitado para proteger a experiência do comprador e evitar que o pedido fique pendente indefinidamente.  
Lembre-se que falhas no controle de estoque e no envio de pedidos poderá gerar penalidades, como a redução do score de SFCR de sua loja, e possíveis restrições a sua capacidade de ofertar produtos por assinatura. (**Please note that failures in inventory control and order fulfillment may result in penalties, such as a reduction in your store's SFCR score and possible restrictions on your ability to offer products through subscription**)

# Perguntas frequentes

**P: Quais categorias são elegíveis para o programa Programa de Assinatura?**   
R: Atualmente, o Programa de Assinatura está disponível para categorias selecionadas de bens de consumo de giro rápido, incluindo saúde, beleza e cuidados pessoais, alimentos e bebidas, produtos para pets e itens essenciais para o lar. A elegibilidade de categorias pode ser ampliada ao longo do tempo.  
**P: Preciso ser um vendedor que esteja no Programa de Taxas de Envio (SFP) para participar?**   
R: Sim. Atualmente, apenas os vendedores inscritos no programa **Programa de Taxas de Envio (SFP)** são elegíveis, para garantir que os assinantes desfrutem de uma experiência consistente de frete grátis.  
**P: Quais métodos de pagamento aceitam assinaturas?**   
R: As assinaturas exigem métodos de pagamento compatíveis com pré-autorização (cobranças recorrentes automáticas). No Brasil, isso inclui cartões de crédito, PIX, Apple Pay e Google Pay.  
**P: Posso alterar o desconto depois que os assinantes já tiverem feito a assinatura?**   
R: Você pode aumentar o desconto (beneficia todos os assinantes imediatamente). Se você reduzir o desconto, ele se aplicará apenas aos novos assinantes — os assinantes atuais mantêm a porcentagem original.  
**P: O que acontece se o pagamento de um assinante falhar?**   
R: O sistema notificará o assinante por e-mail e por mensagem na caixa de entrada. Se o problema não for resolvido, o pedido de assinatura referente a esse ciclo poderá ser ignorado ou cancelado.  
**P: Os assinantes serão notificados antes do envio de cada pedido recorrente?**   
R: Sim. Os assinantes recebem um lembrete antes que cada pedido agendado seja processado, o que lhes dá a oportunidade de pular ou modificar o pedido, se necessário.
