# Onde posso editar as informações do meu produto?

Acesse "Produtos gerenciados" se precisar editar os preços de varejo do seu produto ou adicionar, excluir ou editar um SKU enquanto ele estiver cadastrado em uma campanha.

Editar ou adicionar um SKU em "Produtos gerenciados" interromperá o sistema de preços promocionais da campanha e acionará um erro de SKU. Isso significa que seu ID de produto (PID) não pode participar da campanha. Para resolver isso, você deve descadastrar o produto e cadastrá-lo novamente antes do prazo final da campanha.  

# **Durante uma campanha, quais informações sobre as dimensões do produto podem ser modificadas?**

Quando um vendedor altera a definição de dimensões de atributo variante (por exemplo, adicionando ou removendo uma dimensão de atributo variante, como adicionar "tamanho" além de "cor"), o sistema gera novamente todos os IDs de SKU para esse produto. Isso causa a perda dos dados de cadastro na campanha vinculados aos IDs de SKU originais.  
**Operações que não acionam alterações em IDs de SKU**As seguintes edições são aceitas enquanto seu produto estiver cadastrado em uma campanha:  

* Modificação de informações de atributos não variantes, como nome do produto, preço de SKU, estoque, etc.
* Edição de SKUs: adicione ou exclua valores de atributos nas dimensões de atributo variante existentes (por exemplo, adicione um SKU "verde" na dimensão "cor", mantendo os IDs de SKU "vermelho" e "azul" originais inalterados).
  + Preço de varejo
  + Nome do produto
  + Estoque do produto
  + Exclusão de SKUs

# **Durante uma campanha, quais informações sobre as dimensões do produto não podem ser modificadas?**

Algumas modificações podem fazer com que um produto seja removido da campanha, por isso não é recomendável fazer alterações depois que a promoção já tiver sido cadastrada.  
Isso inclui adicionar ou remover dimensões de atributos variantes — por exemplo, alterar uma única dimensão "cor" para uma dimensão combinada "cor+tamanho".  
**Exemplo**

* Produto original: SKU1 (vermelho), SKU2 (azul)
* Após alterar as dimensões para "cor (vermelho, azul) + tamanho (P, M)":
  + Os IDs de SKU antigos (SKU1, SKU2) se tornam inválidos.
  + Novos IDs de SKU são gerados: vermelho‑P, vermelho‑M, azul‑P, azul‑M.
* Resultado: todos os IDs de SKU antigos são inválidos e o sistema cria um conjunto completamente novo de IDs de SKU. Todas as informações vinculadas aos SKUs originais (incluindo o cadastro na campanha) serão perdidas. Consequentemente, qualquer produto que tenha sido previamente cadastrado na campanha será removido dela. Caso deseje voltar a participar, esses itens deverão ser cadastrados novamente na campanha.

# Após alterar o ID de SKU, o produto foi removido da campanha. Como posso cadastrar novamente o produto na campanha?

Quando o ID de SKU é alterado, o produto é automaticamente excluído da campanha, tornando o produto previamente cadastrado inválido. Na página de detalhes da campanha, na seção de status de cadastro do produto, você verá a etiqueta: "Precisa ser cadastrado novamente".

Os vendedores precisam se inscrever novamente na campanha. O processo de inscrição é o seguinte:  
**Etapa 1: no módulo "Campanha", encontre a campanha na qual deseja se inscrever e clique em Inscrever-se.**

**Etapa 2: acesse a página de detalhes da campanha e carregue os produtos que precisam ser cadastrados novamente.**

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/c717689bb6cb4f4ca1468f185021cb74~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086069280&x-signature=iT%2BmJT5Gy3rO%2FrBCZpZZmhT0Ku0%3D)

**Etapa 3: insira o preço promocional da campanha (e, se aplicável, o estoque reservado para a campanha). Clique em "Enviar" para se inscrever novamente. Isso resolverá o erro de SKU.**
