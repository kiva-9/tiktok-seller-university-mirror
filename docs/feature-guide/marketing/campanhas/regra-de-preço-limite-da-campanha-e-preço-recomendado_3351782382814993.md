## **O que é preço limite de campanha?**

Cada campanha tem os próprios requisitos de preço. Ao se inscrever em uma campanha, após carregar os produtos, você deverá preencher o preço da campanha. Você notará que a faixa de preço inserida tem um limite máximo, que é o preço mínimo da campanha. O preço enviado pelo vendedor deve ser inferior ou igual a esse preço mínimo da campanha.  

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/9a7ff92202ad420da983a68b6ae4cd23~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143419&x-signature=ulg957tuURs5HNqRkxC2cnezqqg%3D)

**Regras de preço limite da campanha**Atualmente, o preço limite da campanha na região da América Latina se baseia principalmente nestes quatro tipos de preço:  

|  |  |
| --- | --- |
| **Regras de limite** | **Definição** |
| Preço de varejo | O preço da campanha deve ser: uma porcentagem (%) **inferior** ou uma porcentagem (%) **inferior ou igual** ao preço de varejo |
| Preço com desconto do vendedor | O preço da campanha deve ser inferior ao preço com desconto do vendedor (ou seja, desconto do produto) |
| Preço histórico mais baixo da LXXD | O preço da campanha deve ser inferior/igual ao preço histórico L30/60/90/180D, que não inclui promoções selecionadas da plataforma e promoções do vendedor |
| Comparação de preços entre plataformas para o mesmo produto | Os preços fora da plataforma são obtidos com a análise de preços de produtos concorrentes anunciados publicamente, que são então validados por um algoritmo de competitividade de preços antes de serem considerados nos cálculos. |

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/f766362c0b144883a3ba551eadca6e3b~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143411&x-signature=yW0S6nB%2FcH8AgRULc7s9sULs19U%3D)

## **O que é o preço recomendado?**

**O preço recomendado da campanha** é uma referência de preço que a plataforma sugere aos lojistas quando eles inscrevem um produto em uma campanha. Não é obrigatório, mas seguir essa prática ajuda o produto a se manter competitivo e em conformidade com as políticas de preços da plataforma. Quanto maior o desconto oferecido pelo vendedor, mais suporte e recursos você poderá receber da plataforma.  

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/7bc16bd3ea934759a3f4303e5987264b~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143434&x-signature=tUfce%2FlJjZMDAVAiijO2kocDB84%3D)

O valor exato do preço recomendado varia de acordo com a configuração de cada campanha. Seguem alguns exemplos comuns (lista não exaustiva):  

* Desconto percentual baseado nos últimos 30 dias (ex.: “xx% de desconto sobre o menor preço dos últimos 30 dias”).
* Comparação de preços externa: comparar o produto com o mesmo item anunciado em plataformas externas.
* …etc. (outros tipos de regras também podem ser aplicados)

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/78182ae14b0543cca0695ac5c30021d8~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143411&x-signature=fnzRtLXgYPUkQAZrsv7KxdmeaZQ%3D)

## **Como é calculado o preço mais baixo da LxxD? Quais descontos estão incluídos e quais são excluídos?**

**A regra geral de cálculo do preço mais baixo histórico de um produto nos últimos x dias é**: o preço mais baixo de um **único produto vendido** pelo vendedor durante uma promoção, excluindo promoções da plataforma (taxas de envio, subsídios da plataforma, cupons da plataforma) e alguns descontos do vendedor (ofertas relâmpago do vendedor, promoção de vários itens do vendedor).

Com base nas regras acima, para determinar se o preço de um produto em diferentes campanhas e ferramentas promocionais será contabilizado para o preço mínimo, é necessário esclarecer quatro pontos:

1. **Se o pagamento foi bem-sucedido:** os produtos cujo pagamento não foi bem-sucedido não serão contabilizados para o preço mais baixo histórico. **Apenas os produtos com "pagamento bem-sucedido" serão contabilizados.**
2. **Quais promoções são usadas para o produto:** os descontos do vendedor serão contabilizados no preço mais baixo histórico, mas os cupons não serão contabilizados no preço mais baixo.

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
|  | **Promoção do vendedor** | | | **Promoção da plataforma** | | |
| * Descontos do vendedor * Oferta conjunta * Preço de campanha | Oferta relâmpago do vendedor | Promoção de vários itens (cupom do vendedor, BMSM, compra com brinde) | Subsídio | Cupom da plataforma | Promoção de vários itens |
| Se é contabilizado no preço mínimo de recrutamento | ✅ | ❌ | | ❌ | | |

3. **Em que nível de promoção eles participam:** o princípio da verificação do preço da campanha é que o preço de campanhas de nível superior não será verificado para campanhas de nível inferior.

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
|  | | **SS** | **S** | **A** | **B** | **Nenhum nível de outro nível** |
| SS | | ✅ | | | | |
| S | | ❌ | ✅ | | | |
| A | | ❌ | | ✅ | | |
| B | | ❌ | | | ✅ | |
| Nenhum nível de outro nível | | ❌ | | ✅ | | |

4. **Em que tipo de campanhas estão participando:** ao configurar portais de recrutamento para grandes promoções, uma tag de campanha será definida, e diferentes tags de campanha correspondem a diferentes mecanismos de preços.

* As tags "Oferta relâmpago", "Oferta para novos clientes" e "Canal de orçamento da marca" **não serão consideradas no preço mais baixo histórico do recrutamento.**
* **Quando a tag estiver vazia, o preço do produto será contabilizado no preço mais baixo histórico.**

|  |  |
| --- | --- |
|  | 1. **Oferta relâmpago** 2. **Mega oferta relâmpago** 3. **Ofertas para novos clientes** 4. **Canal de orçamento da marca** |
| Se é contabilizado no preço mínimo de recrutamento | ❌ |

**Resumo:** para calcular o preço mais baixo histórico de um produto, primeiro é necessário **remover os preços de pedidos não concluídos**, depois **remover promoções especiais do vendedor (ofertas relâmpago do vendedor, promoções de vários itens [cupons do vendedor, descontos para vários itens, combos])**, depois remover **preços de campanhas com tags de campanha específicas** e, por fim, **verificar o nível da campanha**.

*Nota:*

1. *O preço mais baixo para a L30D é calculado retroativamente a partir do momento em que o vendedor se registra, e podem ocorrer atrasos.*

## **Priorização de preços da campanha**

Se um produto for inserido em duas campanhas no mesmo período, a ordem de prioridade de preço seguirá algumas regras simples nesta ordem:  

### **Nível da campanha**

(ou seja, Megacampanha vs. Campanha diária)  
O preço da campanha definido para campanhas em maior escala teria prioridade. Verifique com a equipe de campanhas/gerentes de contas a escala da sua campanha em comparação com outras campanhas.  
> *Exemplo:*
>
> Produto A na **Campanha A (Megacampanha)**, o preço da campanha é definido em **R$100,00**
>
> Produto A na **Campanha B (Campanha diária)**, o preço da campanha é fixado em **R$ 80,00**
>
> **Resultado:** o preço de **R$** 100,00 será exibido. Isso ocorre porque a Megacampanha (Campanha A) é uma campanha maior do que a Campanha diária.

### **Tipo de campanha**

(Cofinanciada vs. Não cofinanciada)  
Os preços das campanhas cofinanciadas, bem como os preços após os subsídios cofinanciados, terão prioridade.  
> *Exemplo:*
>
> Produto A na Campanha A (Megacampanha com subsídios cofinanciados), o preço da campanha é fixado em **R$ 100,00**
>
> Produto A na Campanha B (Megacampanha sem subsídios cofinanciados), o preço da campanha é fixado em **R$ 80,00**
>
> **Resultado:** o preço de **R$** 100,00 será exibido. Isso ocorre porque a Campanha A tem preços subsidiados cofinanciados.

### **Cupons cofinanciados vs. Subsídios cofinanciados**

Quando um produto tem tanto desconto direto cofinanciado quanto cupom cofinanciado ativos, os dois podem ser combinados. O valor mínimo de gastos para o cupom cofinanciado deve ser calculado com base no preço após a aplicação do desconto direto cofinanciado (ou subsídio cofinanciado para produtos populares).  
> Exemplo: o produto A tem um preço original de MXN 200. Após um desconto direto cofinanciado de -MXN 20, o preço com desconto passa a ser MXN 180. Como isso atende à condição do cupom cofinanciado de "gaste MXN 100 e ganhe MXN 20 de desconto", são deduzidos mais MXN 20, resultando em um preço final de MXN 160.

### **Preço**

Se o preço ainda não tiver sido decidido após a filtragem pelas duas primeiras regras, o **preço mais baixo** entrará em vigor e será exibido.  
> *Exemplo:*
>
> Produto A na Campanha A (Megacampanha com subsídios cofinanciados), o preço da campanha é fixado em **R$ 100,00 (com preço subsidiado de R$ 80,00)**
>
> Produto A na Campanha B (Megacampanha sem subsídios cofinanciados), o preço da campanha é fixado em **R$100,00 (com preço subsidiado de R$ 70,00)**
>
> **Resultado:** o preço da campanha de **R$**70,00 será exibido. Isso ocorre porque a Campanha B tem o preço mais baixo após os subsídios.

## **Como alterar os preços da campanha após o registro?**

### Os vendedores podem editar os preços das campanhas na Central do vendedor

Os vendedores podem atualizar o preço da campanha por conta própria na Central do vendedor, acessando a subcampanha específica, visualizando a lista de produtos registrados e clicando em **[Editar].****Exceção:** no caso de uma campanha de subsídio cofinanciada, se o subsídio da plataforma não tiver sido aplicado e o status estiver como "Em análise", os vendedores não poderão editar o preço da campanha na fase "Em análise". Os vendedores precisarão aguardar até que o produto esteja com o status "Aprovado" para editar o preço da campanha.  

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/0a8fe1b5210141dd94c61e2b1f8cd3c9~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143415&x-signature=C29jnVzE7KaPlMxAUUJPP5sPI0s%3D)

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/95f0473dd3a54fbd8cc24fa5fefe53a1~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143417&x-signature=c6Y6Ay8mubMWIwPjdlVXM4tRTw4%3D)

Para editar um preço, **atualize o preço no campo "Preço de venda da campanha"** e clique em **[Enviar].** Após o envio, você verá um resumo da solicitação enviada na Central do vendedor. As solicitações serão **normalmente analisadas e aprovadas/rejeitadas em até 5 dias úteis.****Nota:** enquanto a campanha estiver em andamento, as reduções de preço serão aprovadas normalmente.  
No entanto, os aumentos de preço nem sempre são aprovados, especialmente se não atenderem aos requisitos mínimos da campanha. Se desejar aumentar o preço da campanha após se inscrever nela, primeiro você deve cancelar sua inscrição e depois se inscrever novamente.

## **Perguntas frequentes**

### **Quando um produto não possui um preço mínimo histórico dentro da LxxD, qual lógica determina o preço de registro sugerido para as campanhas?**

Quando os dados históricos de pedidos não estão disponíveis para um produto, o preço limite é determinado de acordo com as regras de precificação da campanha específica. Os preços de referência comuns incluem o preço de varejo, o desconto do vendedor e a comparação de preços entre plataformas.  

### **O preço pago pelo consumidor por um produto difere do valor que o vendedor realmente recebe. Qual poderia ser a razão?**

Uma das principais razões para essa discrepância é que o produto recebeu um subsídio do TTS (financiado pelo TTS).  
Quando um produto tem um subsídio da plataforma, o consumidor recebe um subsídio extra além do desconto do comerciante, de modo que o preço líquido para o consumidor acaba sendo inferior ao valor que o comerciante realmente recebe.  

* Observação: O preço final exibido na página de detalhes do pedido refere-se ao **preço que o consumidor paga**, não ao preço de liquidação para o vendedor.

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/a80e2d8b77454de9954060bbe6100ac9~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2086143420&x-signature=NQr2w2W%2FXwfnoEz%2BTHoP9MpHp%2BU%3D)

### **Por que o preço da campanha do produto registrado não surtiu efeito para o consumidor? Como solucionar esse problema?**

**1) Verifique o status do registro**Acesse a Central do vendedor → Lista de campanhas e confirme se o produto está marcado como "Agendado" ou "Aprovado".  
Se ainda aparecer "Em análise" ou "Rejeitado", o preço não será exibido no front-end.  
**2) Verifique o período da campanha**Certifique-se de que a hora atual esteja dentro das datas de início e término da campanha.  
Uma campanha que ainda não começou ou que já terminou manterá o preço inativo.  
**3) Inspecione o estoque e o estado dos produtos**Quando o estoque do SKU é insuficiente ou zero, a plataforma oculta o preço da campanha.  
**4) Conflito entre várias campanhas**Se o mesmo SKU participar de mais de uma campanha, o TikTok seleciona o preço com base nas regras de prioridade (consulte a Parte 4 deste artigo).  
Uma campanha diferente com um preço mais alto ou mais baixo pode substituir a que você acabou de registrar.  
Para obter informações sobre a lógica exata de acúmulo, consulte o guia Regras de acúmulo de preços.**5) Se o preço ainda não foi aplicado**Se você verificou as informações acima, mas ainda não consegue entender por que o preço não foi aplicado, entre em contato com seu gerente de contas (AM) e forneça as seguintes informações:  

1. O SKU do produto
2. O ID da campanha em que se registrou
3. Os detalhes da explicação de preços exibidos na Central do vendedor

### **Se você tiver alguma dúvida sobre o preço da sua campanha, o que deve fazer?**

* Conforme mencionado acima, você pode usar o **Cartão de explicação de preços** na Central do vendedor para entender a lógica de cálculo do preço da campanha e a origem dos pedidos com preços mais baixos.
* Se você ainda tiver dúvidas sobre o preço da campanha, entre em contato com seu gerente de contas e siga estas etapas:

1. Clique no botão "Ver detalhes do pedido" neste cartão.  
 2. Localize o ID do pedido com o preço mais baixo.  
 3. Forneça esse ID do pedido ao seu gerente de contas para obter mais assistência.

### Após me registrar em uma campanha, posso aumentar o preço de varejo dos produtos que já foram aprovados?

Após se registrar em uma campanha, você pode aumentar o preço de varejo do produto, mas o preço da campanha só pode ser reduzido, não aumentado. Observe a diferença entre o preço de varejo do produto e o preço da campanha.
