# **O que é uma Amostra Reembolsável?**

As Amostras Reembolsáveis permitem que você teste produtos **sem riscos**.  
Você paga pela amostra antecipadamente — se seu conteúdo comprável tiver bom desempenho, você recebe **o reembolso total**.  

# **Como funciona:**

* Procure produtos com o selo **"Amostra Reembolsável"**
* Compre a amostra por conta própria
* Publique conteúdo ou gere vendas dentro de **90 dias** (os critérios podem variar de acordo com o vendedor)
* Se os compradores não devolverem os itens em **14 a 30 dias**, você recebe seu dinheiro de volta

**Dica:** Verifique os critérios de reembolso de cada amostra para garantir que você se qualifique!
