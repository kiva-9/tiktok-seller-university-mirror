# **Visão geral**

Este artigo explica o que é a Visão geral da Bússola de dados e como usá-la para visualizar dados importantes rapidamente, bem como acessar números de dados detalhados por meio de pontos de entrada.

# **O que é a Visão geral da Bússola de dados?**

Como o nome sugere, a Visão geral da Bússola de dados é uma página que apresenta uma visão panorâmica ou uma rápida olhada nos números importantes da sua loja. Mas também é onde você pode acessar dados detalhados relacionados a transmissões LIVE, vídeos e Cartão do produto acessando as seções relevantes.

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/5a22f036ebd84b9ba766c3fcd060c70a~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059612923&x-signature=qWp1l6WgJf7HW%2BxDEpJjLT6A3cw%3D)

# **Noções básicas sobre dados de negócios na Visão geral da Bússola de dados**

1. Acesse Bússola de dados > [Visão geral](https://seller-br.tiktok.com/compass/data-overview "https://seller-br.tiktok.com/compass/data-overview"). Dados de negócios é a guia principal na Visão geral da Bússola de dados e há duas métricas de grupo nela:
   1. **Vendas:** Valor Bruto da Mercadoria (GMV), Itens vendidos, Compradores, Reembolsos, Pedidos de SKU, Pedidos
   2. **Tráfego:** Visualizações de página, Visitantes e Taxa de conversão

# **Acompanhe as vendas em diferentes fontes**

1. Primeiro, escolha a classificação entre o GMV mais alto ou Maioria das visualizações e períodos (Ontem ou Últimos 7 dias) para:
   1. **LIVE**
   2. **Vídeos**
   3. **Cartões dos produtos**
2. Você poderá ver o GMV nas três seções.
   1. GMV da LIVE em contas auto-operadas.
   2. GMV do Vídeo em contas auto-operadas.
   3. GMV do Cartão do produto em canais de tráfego, incluindo contas auto-operadas e afiliadas.

      ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/9e2372e161a148019bb7cc699f2d41fc~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059612927&x-signature=GKsb5MjiroiyjFxyWi6BH9vhSTc%3D)
3. Em seguida, veja as **3 principais** transmissões LIVE, vídeos ou cartões de produtos no perímetro escolhido.
   1. Para uma inspeção mais detalhada, basta clicar em Visualizar análise em qualquer uma das três guias. Por exemplo, LIVE > Visualizar análise > Desempenho das transmissões LIVE.

      ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/65ff863ed9a5477a84bb3d7e1b7731c3~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059612926&x-signature=%2BGSDcZDohQ6thhc8w9cq5onVb0c%3D)

# **Perguntas frequentes**

1. O GMV mostrado em Bússola de dados é igual à minha renda no TikTok Shop?

* Não. O GMV representado aqui é o desempenho da sua Loja, **incluindo devoluções, reembolsos e cancelamentos.** Para quaisquer dúvidas e preocupações financeiras, acesse a [página Finanças na Central do vendedor](https://seller-br.tiktok.com/finance/bills?subTab=on-hold&tab=overview "https://seller-br.tiktok.com/finance/bills?subTab=on-hold&tab=overview").

2. Posso ver dados mais detalhados na página Visão geral da Bússola de dados?

* A página Visão geral foi projetada para facilitar a visualização de dados principais (como GMV e itens vendidos) para que você possa estar ciente desses números importantes. Dito isso, colocamos pontos de entrada com cuidado e intencionalmente em toda a página, para que você possa obter um monitoramento de dados mais detalhado. Por exemplo, a guia Fontes de vendas fornece entradas para desempenho das transmissões LIVE, desempenho dos vídeos e desempenho do cartão do produto.

3. E quanto aos produtos?

* Consulte [Bússola de dados > Produto > Desempenho de produtos](https://seller-br.tiktok.com/compass/product-analysis?timeRange=2025-04-02%7C2025-04-02&shortcut=today "https://seller-br.tiktok.com/compass/product-analysis?timeRange=2025-04-02%7C2025-04-02&shortcut=today") para verificar tudo o que está relacionado aos seus produtos.

4. Dados da guia Loja?

* Assim como a página Visão geral da Bússola de dados, a página Visão geral da guia Loja também passou por uma renovação! Para visualizar, acesse a [guia Loja > Visão geral](https://seller-br.tiktok.com/compass/data-overview "https://seller-br.tiktok.com/compass/data-overview").

5. Onde posso visualizar o GMV do afiliado?

* Acesse o [Centro de Afiliados > Análise](https://affiliate.tiktok.com/data/product-performance?shop_region=BR "https://affiliate.tiktok.com/data/product-performance?shop_region=BR") para obter uma perspectiva do desempenho do produto afiliado.

6. Onde posso ver LIVEs e vídeos auto-operados?

* Vá para a guia Fonte de vendas.

7. Os dados sobre GMV do afiliado e auto-operados são em tempo real?

* Para obter dados em tempo real, vá para a página [Transmissão LIVE e vídeo](https://seller-br.tiktok.com/compass/live-analysis "https://seller-br.tiktok.com/compass/live-analysis").
