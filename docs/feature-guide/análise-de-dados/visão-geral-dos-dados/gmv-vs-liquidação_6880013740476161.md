Você sabe a diferença entre GMV e liquidação?

Detalhamos as definições entre GMV e liquidação no TikTok Shop para você ter uma visão clara e analisá-las de forma correta.

**DEFINIÇÕES:**

* Está em Central do vendedor > Bússola de dados
* É o valor de vendas gerado a partir de vendas no TikTok Shop, também igual ao valor final pago pelo cliente.
* **GMV =** ***preço original do produto - todos os descontos + taxas pagas pelo cliente*****.**
* Reflete o desempenho de operação da loja antes de deduzir quaisquer taxas de vendedor e ajustes da plataforma.

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/1a3c7c4db99d4eaca5bfef201956f8f8~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059613337&x-signature=I1M8aQSoZ13ntkvV44N6yzn0%2FKs%3D)
* Dicas profissionais: o GMV apresentado aqui é o mesmo que o total de clientes vê quando finaliza a compra!

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/b8643af9b56241529ffcf34147eeab4f~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059613338&x-signature=pHD48SN74429jBdOQOTPqP4J7w4%3D)

* Pode ser acessado em Central do vendedor > Finanças
* É o valor final de retirada que os vendedores recebem após as taxas da plataforma, as taxas logísticas e os ajustes serem deduzidos do valor da venda.
* **Liquidação** **=** ***Receita******total - Taxas totais + Ajustes totais***
* Reflete situações financeiras gerais.

  ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/c980c4b5a5a24abf9129bfc11b26d210~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059613338&x-signature=v0BQrjGrB%2FtBg5s4qpApbzjFcLg%3D)

* **Valor Bruto da Mercadoria (GMV)**
* **Liquidação**

**EXEMPLO:**

|  |  |
| --- | --- |
| Detalhes do pedido | |
| Preço original do produto | R$ 1.000 |
| Descontos financiados pelo vendedor | R$ 100 |
| Taxa de envio paga pelo cliente (paga pelos clientes aos vendedores) | R$ 50 |
| **GMV em** **Central do vendedor > Bússola de dados** | R$ 1.000 - R$ 100 + R$ 50 = **R$ 950** |
| Comissão de afiliados (paga pelos vendedores para marketing de afiliados) | R$ 80 |
| Comissão da plataforma (paga pelos vendedores à plataforma) | R$ 5 |
| Subsídio da plataforma (pago pela plataforma aos vendedores) | R$ 20 |
| **Liquidação em Central do vendedor > Finanças** | (R$ 1.000 - R$ 100 + R$ 50) - R$ 80 - R$ 5 + R$ 20 = **R$ 885** |

**CONCLUSÃO:**

* GMV é o montante de vendas geradas antes de quaisquer custos e ajustes, e reflete a **eficiência operacional das lojas**.
* Liquidação é a **renda final** dos vendedores e reflete a situação financeira geral dos vendedores.
* GMV e liquidação **NÃO** são comparáveis.
