Este artigo ensina como usar a guia Análise do usuário na página Dados para Criadores. Especificamente, esse recurso ajudará você a entender quem são seus seguidores, compradores e espectadores. Com isso, você não apenas entenderá melhor sua base de público-alvo, mas também terá insights práticos para criar conteúdo e aumentar as conversões.

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/253b8be75e72443c821b542f884e193d~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059923604&x-signature=XZUBqizkPwtJagcRtDb%2FRPLTcOM%3D)

# **Onde visualizar a Análise de usuário**

1. Na página Dados de hoje no aplicativo TikTok para criadores, role para a direita até ver a guia Análise de usuários. A entrada também pode ser visualizada na guia Visão geral.

|  |  |
| --- | --- |
| image | image |

2. Na guia Análise de usuário, há métricas principais:

* **Espectadores principais**
* **Compradores**
* **Seguidores**

3. Selecione o período entre **Últimos 7 dias**, **Semana**, **Mês**. Últimos 7 dias por padrão.
   1. Observe que a seleção do período na guia Visão geral difere da guia Análise do usuário, o que significa que se você tiver escolhido qualquer um dos períodos na guia Visão geral que não esteja disponível na Análise do usuário, ou seja, Hoje, Ontem, Dia ou Personalizado, o **período padrão selecionado na Análise do usuário será Últimos 7 dias**.
   2. Mas se você tiver escolhido qualquer um dos períodos na guia Visão geral que também está disponível na Análise do usuário, ou seja, Últimos 7 dias, Semana, Mês, a seleção permanecerá.

      ![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/20d59322649e4bdc842ab2a89351725b~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059923603&x-signature=1kPHfn8251mulOb796o0dgfN7nI%3D)

# **Como visualizar dados na Análise do usuário**

1. Cada métrica tem um detalhamento de sua posição no mercado, gráfico de tendências, perfis de usuário, produto, preferências de conteúdo, bem como pontos de entrada para informações mais detalhadas.

# **Perguntas frequentes**

1. Os dados são em tempo real?

* Não, os dados não são em tempo real.

2. Preciso ter um número mínimo de espectadores, compradores ou seguidores para visualizar os dados?

* Sim, você precisará de pelo menos 1.000 espectadores, compradores ou seguidores de conteúdo para exibir dados.
