Neste artigo, ajudaremos você a adicionar produtos aos seus vídeos. Para que um Criador de afiliados ganhe comissões, ele deve incluir posicionamentos de produto em seu conteúdo ou conta.

Os vídeos curtos são uma excelente maneira de mostrar os pontos de maior venda do produto e a criatividade do criador. Os usuários interessados podem adicionar links de produtos a seus vídeos para ganhar comissão com seu hobby!

## **Como os anúncios de produtos aparecerão nos vídeos curtos?**

Os produtos adicionados a um vídeo curto podem ser comprados por meio do botão **Cesta amarela** conforme mostrado a seguir! O botão de cesta amarela solicita seu link direto para que um Criador receba comissão por cada produto adquirido.

|  |  |
| --- | --- |
| **Na página FYP** | **Tocando na Cesta amarela** |
| image | image |

Lembre-se: você só pode receber comissão com as vendas geradas por produtos adicionados à sua vitrine e conteúdo!

![image](https://p16-oec-university-sign-sg.ibyteimg.com/tos-alisg-i-nk3i2mqmvs-sg/63d914fac6194a26b7b50730c3c0d1e5~tplv-nk3i2mqmvs-image.png?lk3s=5d1a069b&x-expires=2059920348&x-signature=MXWLTpRLvMkwO9OboH7i%2FBrCLOs%3D)

## **Como adicionar a cesta amarela aos seus vídeos**

|  |  |  |  |
| --- | --- | --- | --- |
| image | image | image | image |
| **Etapa 1:** Crie seu vídeo para o afiliado | **Etapa 2:** Quando concluir a edição, toque em **Adicionar link** | **Etapa 3:** Na vitrine, selecione os produtos que serão adicionados ao vídeo | **Etapa 4:** Após adicionar os produtos, eles aparecerão na página de edição conforme mostrado acima! |

## **Perguntas frequentes**

1. Qual é a quantidade máxima de links de produto que o Criador pode adicionar a um vídeo?
   * 1 link de produto
2. Onde posso localizar os produtos a serem adicionados aos meus vídeos?
   * Somente os produtos que estão na vitrine da sua conta podem ser adicionados ao vídeo. Você encontrará os produtos no Marketplace, na Aba Loja ou, até mesmo, no FYP.
