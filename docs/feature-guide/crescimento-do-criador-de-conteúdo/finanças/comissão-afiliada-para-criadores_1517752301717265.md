# **O que é a comissão afiliada?**

A comissão afiliada é aquela que você recebe como criador quando coopera com um comerciante para promover os produtos. Você receberá uma comissão sobre cada item vendido por meio do seu conteúdo.

---

## **Regras de cálculo**

As comissões são calculadas com base na Base de Comissão × taxa de comissão. A Base de Comissão corresponde ao preço real pago pelo comprador mais quaisquer reembolsos de subsídios da plataforma.

\*Nota: a Base de Comissão pode ser diferente do preço exibido na loja devido a subsídios da plataforma e outros ajustes.

|  |  |  |
| --- | --- | --- |
| **Termo** | **Definição** | **Exemplo** |
| Preço real pago pelo comprador | Valor pago pelo comprador no checkout | R$100 |
| Reembolso de subsídio da plataforma | Desconto financiado pela plataforma adicionado de volta | +R$10 |
| **Base de Comissão** | Preço real pago + reembolso de subsídio da plataforma | **R$110** |
| Taxa de comissão | Definida pelo comerciante | 10% |
| **Comissão Estimada** | Base de Comissão × taxa de comissão | **R$11** |

**Por que não recebi nenhuma comissão afiliada?**

Não haverá comissão nos seguintes casos:

* Se o comprador cancelar o pedido antes de receber a remessa;
* Se o comprador reembolsar o pedido durante o período pós-venda.
* Se o comprador confirmar o recebimento, mas um reembolso parcial ocorrer durante o período pós-venda, o criador receberá parte da comissão.
* Se o comprador não concluir o pedido sob o pretexto de fraude.

**Por que recebo a minha comissão após o período de liquidação padrão?**

De acordo com os [Termos de uso do criador](https://seller-br.tiktok.com/university/essay?knowledge_id=3275818982590224&identity=1 "https://seller-br.tiktok.com/university/essay?knowledge_id=3275818982590224&identity=1"), só é possível receber a comissão **após** os pedidos do vendedor serem liquidados. Assim, o pagamento das comissões do criador dependerá do tipo de período de liquidação do vendedor. Existem três tipos de períodos de liquidação que podem ser aplicados à loja de um vendedor:

|  |  |
| --- | --- |
| 1. Liquidação padrão | Período de liquidação de fundos de 7 dias corridos para pedidos de clientes |
| 2. Liquidação expressa | Período de liquidação de fundos de 3 dias corridos para pedidos de clientes |
| 3. Liquidação prolongada | Período de liquidação de fundos de 15 dias corridos para pedidos de clientes |

Para saber mais sobre os períodos de liquidação dos vendedores, consulte o [Guia de política](https://seller-ph.tiktok.com/university/essay?knowledge_id=1721378948548354&role=1&course_type=1&from=search&identity=1 "https://seller-ph.tiktok.com/university/essay?knowledge_id=1721378948548354&role=1&course_type=1&from=search&identity=1").

## **Comissão estimada vs. comissão**

**Comissão estimada:** após o comprador pagar pelo pedido, o sistema calculará uma comissão estimada

* Comissão estimada = Base de Comissão × taxa de comissão + bônus de comissão da plataforma + comissão de publicidade

Nota: a comissão estimada é um valor preliminar. A comissão real final pode ser diferente, pois os pedidos reversos (reembolsos, devoluções, cancelamentos) ainda não foram deduzidos.

**Comissão real:** a comissão real varia de acordo com as diferentes situações durante o período pós-venda.

* Se não ocorrer reembolso, comissão real = comissão estimada
* Se ocorrer um reembolso parcial, comissão real = (Base de Comissão – valor do reembolso) × taxa de comissão
* Se ocorrer o reembolso total, comissão real = R$ 0

|  |  |  |
| --- | --- | --- |
|  | **Comissão Estimada** | **Comissão Real** |
| Quando calculada | Logo após o pagamento do comprador | Após o término do período pós-venda |
| Fórmula | Base de Comissão × taxa + bônus de comissão da plataforma + comissão de publicidade | Com base no valor liquidado final |
| Inclui pedidos reversos (reembolsos/devoluções/cancelamentos)? | ❌ Ainda não deduzidos | ✅ Já deduzidos |
| Onde verificar | Creator Compass | Página de Receita |

# **Perguntas frequentes**

1. **Por que a minha comissão real está como US$ 0 na página Não liquidado?**
   * Para todas os pedidos na página Não liquidado, a comissão é de US$ 0. As comissões só serão enviadas após os pedidos serem liquidados.
2. **Sou comerciante. Como distinguir a receita de promoção afiliada e a receita de venda autônoma do comerciante?**
   * Na bússola de dados da central de vendas online, você pode escolher ver a receita de **Todos** e de **Afiliados**:

**Todos:** promoção de venda autônoma do comerciante + promoção afiliada

**Afiliados:** apenas a receita da promoção afiliada
