# Introdução ao recurso

## O que é a LIVE de loja única?

**LIVE de loja única** é um formato de LIVE em que a sua sessão de LIVE apresenta produtos de apenas uma loja. Você escolhe uma loja para promover e toda a sua transmissão é dedicada aos produtos dessa loja.

# Manual de instruções

## Como autorizar

|  |  |
| --- | --- |
| **Tutorial passo a passo** | **Interface do usuário** |
| Dois cenários, ambos começando a partir da **página Perfil**:  **Cenário A: nunca autorizado anteriormente.** Na página **"Ganhe mais tráfego e comissões com anúncios da loja"**, ative **Autorização de vídeo** e **Autorização de LIVE** e, em seguida, toque em **Pronto**.  **Cenário B: autorização de anúncios em vídeo já feita.** Na página **"Atualização de autorização"**, confirme a **Autorização de LIVE** e, em seguida, toque em **Pronto**.  💡 Você pode atualizar a qualquer momento em **Central de criadores > Configurações > Configurações de privacidade**.  image | image |

## Como selecionar produtos para sua LIVE de loja única

|  |  |
| --- | --- |
| **Tutorial passo a passo** | **Interface do usuário** |
| **Etapa 1:** abra a **página LIVE de loja única** a partir do banner Mercado de produtos.  **Etapa 2:** busque os vendedores recomendados e abra a loja que você deseja apresentar.  **Etapa 3:** toque em **Acessar loja** para navegar pelo catálogo. Toque em **Adicionar** para adicionar um produto ou verifique os **detalhes de comissão** primeiro.  **Etapa 4:** toque em **Adicionar à vitrine**. Os produtos estão prontos para a sua LIVE. | image |

## Como iniciar uma LIVE de loja única

|  |  |
| --- | --- |
| **Tutorial passo a passo** | **Interface do usuário** |
| **A. Selecionar LIVE de loja única e adicionar produtos**  **Etapa 1:** toque em **Entrada na LIVE** para iniciar o fluxo pré-LIVE.  **Etapa 2:** selecione **LIVE de vendedor único** e, em seguida, toque em **Avançar**.  **Etapa 3:** selecione a loja que deseja apresentar e, em seguida, toque em **Avançar**.  **Etapa 4:** toque em **Adicionar** para adicionar os produtos da loja. | image |
| **B. Mudar para outra loja**  **Etapa 1:** na página da loja atual, abra o seletor **tipo de LIVE** novamente.  **Etapa 2:** mantenha **LIVE de vendedor único** e toque em **Confirmar**.  **Etapa 3:** selecione a nova loja que deseja apresentar.  **Etapa 4:** no prompt **"Mudar para [Loja]?"**, toque em **Mudar** (os produtos da loja anterior serão removidos).  **Etapa 5:** toque em **Adicionar produto primeiro** para adicionar os produtos da nova loja. | image |

## Como verificar o desempenho da LIVE de loja única

|  |  |
| --- | --- |
| **Tutorial passo a passo** | **Interface do usuário** |
| Acompanhe sua LIVE de loja única na **Central de criadores**. Cada uma possui um **selo de LIVE de loja única** nos relatórios.  **Etapa 1:** abra a **Central de criadores > Dados** para ver as principais métricas: GMV, itens vendidos e comissão estimada.  **Etapa 2:** acesse a aba **LIVE**.  **Etapa 3:** na **lista de LIVEs**, identifique as LIVEs de loja única pelo selo.  **Etapa 4:** toque em uma sessão para ver os **detalhes da LIVE**: GMV, conversão e diagnóstico. | image |

## Como verificar a comissão da LIVE de loja única

|  |  |
| --- | --- |
| **Tutorial passo a passo** | **Interface do usuário** |
| Acompanhe cada pedido da LIVE de loja única na **página Pedidos de afiliados**. **Etapa 1**: acesse a Central de criadores e toque em Receita no kit de ferramentas do TikTok Shop.**Etapa 2**: na página Receita, toque em Pedidos de afiliados.**Etapa 3**: na lista Pedidos de afiliados, busque os pedidos de LIVEs de loja única; eles são marcados com um selo de LIVE e mostram a taxa de comissão correspondente e o status da liquidação.**Observação**: as taxas de comissão podem variar entre pedidos impulsionados por anúncios e pedidos orgânicos. Verifique os detalhes do pedido para saber a taxa efetivamente aplicada. | image |
