## **Proteção e Alertas da Plataforma**

Nesta seção, o sistema exibe alertas de risco identificados pelas políticas de segurança da plataforma.  

* Para fraudes confirmadas (por exemplo, reembolsos maliciosos ou avaliações falsas): O sistema bloqueia automaticamente essas ações e mostra os resultados aos vendedores.
* Para pedidos/reembolsos de alto risco: O sistema os sinaliza para análise do vendedor. Os vendedores podem, então, cancelar esses pedidos sem penalidades para proteger seus negócios.

### **Pedidos com Alerta de Segurança**

Estes são pedidos que a plataforma determinou como tendo um alto risco de cancelamento. Para esses pedidos, o sistema irá:  

* Sinalizar o pedido com uma **Tag de Risco** no painel do vendedor.
* Permitir que os vendedores cancelem manualmente esses pedidos.
* Isentar penalidades de desempenho para cancelamentos de pedidos sinalizados.

### **Reembolsos com Risco**

Estas são solicitações de devolução/reembolso que a plataforma determinou como "arriscadas". Para essas solicitações, o sistema irá:  

* Sinalizar a solicitação com uma Tag de Risco em seu painel.
* Permitir que você "Rejeite" a solicitação.
* Isentar penalidades de desempenho pela sua rejeição.

## **Bloqueio de Compradores**

Se você identificar compradores envolvidos em comportamentos maliciosos, poderá adicioná-los à **[Lista de Bloqueio]** para evitar pedidos futuros desse comprador. Observe que o uso deste recurso deve ser feito de forma objetiva e justa. Se notarmos qualquer abuso deste recurso, encerraremos o seu uso imediatamente e poderemos aplicar medidas disciplinares mais severas à sua conta.  
**O que acontece se eu bloquear um comprador?**

* O comprador não poderá fazer novos pedidos em sua loja.
* O comprador ainda poderá:
  + Enviar mensagens privadas para você.
  + Avaliar ou solicitar suporte pós-venda para pedidos anteriores.

**Nota:** Os vendedores devem continuar a comunicação normal para os pedidos existentes.

  Verifique o nome do usuário / foto do perfil para garantir a precisão.

2. **Escolha um motivo para o bloqueio**
   * Selecione o motivo pelo qual você está bloqueando este usuário. Isso ajuda a plataforma a melhorar a detecção de riscos e a proteger os vendedores.

3. **Selecione o escopo do bloqueio**
   * Bloquear apenas este ID de usuário: Selecione esta opção se quiser bloquear apenas esse ID específico.
   * Bloquear todos os IDs de usuário vinculados: Selecione esta opção se quiser bloquear também todas as contas associadas a esse usuário.

4. **Duração do bloqueio**
   * 90 dias ou Permanente (selecione conforme necessário).

**⚠️ Não abuse deste recurso**

* A plataforma pode investigar os seus motivos para bloquear compradores. Vendedores que abusarem deste recurso podem perder o acesso a ele.
* Em alguns casos, podemos anular os bloqueios se os pedidos forem considerados livres de risco após uma análise.

### FAQ (Perguntas Frequentes)

**Existem limitações para este recurso?**

* Sim, um máximo de 100 usuários pode ser bloqueado. Você pode bloquear no máximo 10 usuários por dia.

**O que eu faço se o usuário me perguntar se eu o bloqueei?**

* Você pode direcionar as dúvidas do cliente para o suporte ao cliente da plataforma.
